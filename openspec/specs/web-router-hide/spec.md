## Purpose

Владелец через веб-консоль временно скрывает конкретный роутер по правилам G04/G05.

## Requirements

### Requirement: The console asks before hiding an exact router

Веб-консоль SHALL показывать последствия временного скрытия и запрашивать отдельное подтверждение для точного RouterID. Изменение SHALL требовать действующую сессию владельца, защиту изменения и совпадение текущего исходного состояния.

#### Scenario: An explicit confirmation hides the selected router

- **WHEN** владелец подтверждает действующий выбор в текущей сессии
- **THEN** видимость меняется атомарно по G05, данные и ключ роутера сохраняются
- **AND** карточка закрывается, обзор перечитывается и получает фокус

#### Scenario: The router returns after hiding

- **WHEN** текущая регистрация отправляет следующий допустимый контакт
- **THEN** в обзоре отображается прежняя запись с тем же RouterID
- **AND** ранее закрытая карточка остаётся закрытой

#### Scenario: The operation is cancelled or becomes stale

- **WHEN** владелец отменяет подтверждение либо исходное состояние или полномочие изменилось
- **THEN** подтверждение не изменяет видимость
- **AND** доступны возврат к карточке либо явная проверка текущего состояния

#### Scenario: The confirmation result is uncertain

- **WHEN** ответ на явное подтверждение потерян
- **THEN** интерфейс запрашивает явное чтение состояния и не повторяет запись автоматически
