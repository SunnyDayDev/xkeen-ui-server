# external-router-variables Specification

## Purpose

Внешний клиент может прочесть и условно изменить персональные значения одного общего элемента роутера.

## Requirements

### Requirement: External clients edit one variable-mode shared element

Доступ SHALL использовать F20 и точные роутер, принятый шаблон и общий UUID. Запись SHALL изменить только запрошенные значения в режиме переменных с проверкой полного основания и допуска в точке записи.

#### Scenario: An exact element read supplies a conditional edit
- **WHEN** допущенный внешний клиент читает известный общий UUID назначенного роутера
- **THEN** ответ содержит только данные этого элемента, состояние режима и сильный ETag его основания

#### Scenario: Literal variable source and explicit inheritance
- **WHEN** клиент подаёт точное предусловие и передаёт исходный JSON либо явно освобождает имя для наследования
- **THEN** меняются только переданные имена, сохраняются точный исходник и остальные настройки, ответ отражает сохранённые значения и диагностики F12

#### Scenario: Wrong source or mode has no effect
- **WHEN** изменились назначение, принятое основание или поколение черновика, либо элемент использует полную замену
- **THEN** запись отклоняется без частичного изменения

#### Scenario: Permit revoked between read and commit
- **WHEN** внешний допуск отозван после чтения, но до сохранения
- **THEN** сохранение отклоняется по правилам F20 без изменения черновика
