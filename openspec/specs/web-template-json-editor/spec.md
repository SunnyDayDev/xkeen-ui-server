# web-template-json-editor Specification

## Purpose

Веб-редактор позволяет открыть и условно сохранить исходный JSON одного элемента общего шаблона.

## Requirements

### Requirement: The administrator can open a scoped template element

Защищённый редактор SHALL читать элементы выбранного шаблона и точный сырой JSON выбранного UUID с версией шаблона. Идентичность и принадлежность элемента SHALL проверяться по полному снимку. Отсутствие шаблона или элемента SHALL иметь определённый результат.

#### Scenario: An existing element is opened from its template
- **WHEN** администратор открывает шаблон, выбирает секцию и UUID
- **THEN** редактор показывает содержимое этого элемента и его UUID, сохраняя исходные байты, включая пробелы и экранирование
- **AND** UUID другого шаблона не используется для подстановки элемента

#### Scenario: Failed loading is distinct from an empty template
- **WHEN** шаблон отсутствует, хранилище недоступно либо полный снимок не удалось прочитать
- **THEN** интерфейс сообщает соответствующий отказ и не предлагает создать элемент как в подтверждённом пустом шаблоне

### Requirement: A first element or selected content is saved intentionally

Сохранение SHALL принимать текущее содержимое редактора и прочитанную версию. В пустом шаблоне первое сохранение SHALL создавать один новый UUIDv4 в выбранной поддерживаемой секции. В существующем элементе SHALL сохраняться UUID, секция, позиция и отключение. Изменения SHALL использовать правила A08.

#### Scenario: One item is created when an empty template is saved
- **WHEN** администратор выбрал поддерживаемую секцию Xray пустого шаблона, ввёл допустимый JSON и явно сохранил его
- **THEN** создаётся ровно один элемент и возвращаются новый UUID и новая версия шаблона
- **AND** пустые секции, уже записанные в шаблоне, сохраняются

#### Scenario: Arbitrary source data round trips
- **WHEN** администратор сохраняет корректный JSON со свободными полями, точным числом, экранированием, нестандартными пробелами и переводами строк
- **THEN** точный текст доступен после перезагрузки, а идентичность, другие элементы и их определения сохранены
- **AND** новая целая ссылка объявляет определение только в редактируемом элементе согласно A08

#### Scenario: A draft can remain incomplete
- **WHEN** синтаксически корректный JSON содержит допустимое для хранения `null` либо неготовую к сборке ссылку
- **THEN** текст можно сохранить как черновик, не меняя принятую или желаемые ревизии

### Requirement: A rejected draft edit retains the open buffer and saved state

Ошибка структуры JSON, версия конкурента или отказ сессии SHALL оставлять сохранённое состояние без изменений и сохранять открытый буфер. Синтаксическая ошибка SHALL указывать место без отражения исходного текста в ответе. Повторный вход SHALL оставлять сохранение явным действием.

#### Scenario: Invalid syntax or duplicate key leaves the draft unchanged
- **WHEN** отправленный текст содержит ошибку JSON либо повтор имени ключа
- **THEN** редактор показывает расположение ошибки, а сохранённый текст и версия не меняются

#### Scenario: Two tabs race to save
- **WHEN** обе вкладки сохраняют разные правки с одной версией, включая две попытки создания первого элемента
- **THEN** сохраняется одна правка, вторая вкладка получает конфликт и удерживает свой буфер без автоматической перезаписи

#### Scenario: The authorizing session ends before the save
- **WHEN** завершение сессии, локальный сброс или истечение опережает запись либо запрос не прошёл проверку origin и CSRF
- **THEN** шаблон не меняется
- **AND** после повторного входа открытый буфер доступен для самостоятельного сохранения

#### Scenario: An inactive browser session receives no draft data
- **WHEN** сессия истекла либо была отозвана к моменту чтения
- **THEN** ответ не содержит исходного JSON, определений или сохранённой версии
