# external-router-catalog

## Purpose

Внешний допущенный HTTPS-клиент читает точные файлы явного источника одного роутера.

## Requirements

### Requirement: External clients receive the exact files and source evidence

Ответ SHALL содержать только полный именованный набор точных файлов выбранного согласованного источника. Представление SHALL различать сохранённую желаемую ревизию после серверной проверки Xray и предпросмотр B12 из версий использованных настроек без проверки Xray. Оба режима сохраняют текущую публикацию и статус применения.

#### Scenario: An authorized client reads an explicit source

- **WHEN** внешний клиент передаёт точный видимый роутер и действительную форму источника
- **THEN** сервер возвращает неизменённые байты, их исходные имена и версионные признаки именно этого источника

#### Scenario: The candidate has a preparation error

- **WHEN** обязательная часть выбранного B12-снимка не собирается
- **THEN** сервер возвращает безопасную диагностику, а файлы и побочные эффекты отсутствуют

#### Scenario: Source or access changes before delivery

- **WHEN** используемая версия или внешний допуск меняются между чтением и формированием результата
- **THEN** выдача исходных файлов и устаревшей диагностики прекращается и возвращается соответствующая безопасная ошибка
