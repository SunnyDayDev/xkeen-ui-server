# web-template-variable-editor Specification

## Purpose

Веб-редактор позволяет настраивать определения переменных одного общего элемента без сборки конфигурации.

## Requirements

### Requirement: The selected element exposes its stored variable definitions

Редактор SHALL показывать сохранённые определения выбранного UUID, точные имена, типы и JSON-значения дефолтов. Сведения SHALL относиться к версии того же снимка. Обязательность персонального значения SHALL вычисляться из отсутствующего или незаполненного дефолта по правилам B01.

#### Scenario: An automatically declared definition is initially required
- **WHEN** после сохранения JSON новая целая ссылка объявила переменную с типом `string` и дефолтом `""`
- **THEN** запись видна в редакторе и ей требуется персональное значение при сборке
- **AND** отдельный переключатель обязательности отсутствует

#### Scenario: Filled defaults are distinct from an absent value
- **WHEN** дефолт равен подходящему по типу `false`, `0`, `{}` или `[]`
- **THEN** он показывается как заполненный и не требует персонального значения
- **AND** отсутствующий дефолт и дефолт с пробельной строкой показываются как незаполненные

#### Scenario: An unused definition remains visible
- **WHEN** сохранённое определение больше не встречается в JSON
- **THEN** оно остаётся доступным в редакторе со своим типом, дефолтом и той же логикой обязательности

### Requirement: Definition edits preserve element data and show validation

Редактор SHALL сохранять тип и дефолт только выбранного элемента при совпадающей версии. Структурный или синтаксический отказ SHALL сохранять данные и версию. Семантические ошибки B01 SHALL отображаться для черновика отдельно от результата сохранения.

#### Scenario: A type change retains an unfilled default
- **WHEN** администратор меняет тип на `number`, оставляя пустой дефолт
- **THEN** тип сохраняется, а дефолт остаётся незаполненным без принудительного преобразования
- **AND** сырой JSON, UUID, точные имена, порядок и остальные элементы остаются прежними

#### Scenario: A malformed default preserves the saved draft
- **WHEN** введён текст дефолта с ошибкой синтаксиса или повтором JSON-ключа
- **THEN** редактор показывает ошибку у дефолта и не меняет сохранённые данные

#### Scenario: A semantically invalid default can be stored in a draft
- **WHEN** дефолт структурно корректен и при этом несовместим с типом или содержит `null`
- **THEN** интерфейс имеет отдельную диагностику сборки и позволяет сохранить неготовый черновик

#### Scenario: A lost session or stale version preserves the edit buffer
- **WHEN** отозвана сессия или другой клиент уже изменил версию шаблона
- **THEN** сохранения не происходит, а пользователь видит отказ и сохраняет локальный открытый буфер
- **AND** повторный вход или получение актуального снимка не отправляет старую правку автоматически

#### Scenario: An inactive browser session receives no draft data
- **WHEN** сессия истекла либо была отозвана к моменту чтения
- **THEN** ответ не содержит исходного JSON, определений или сохранённой версии

#### Scenario: Explicitly saving a legacy element discovers its own absent whole reference
- **WHEN** определение для целой ссылки в выбранном элементе ранее не было сохранено, и владелец явно сохраняет его определения
- **THEN** A08 добавляет начальное определение только в этот элемент, сохраняя исходный JSON и порядок уже записанных имён
- **AND** простое чтение не изменяет записи
