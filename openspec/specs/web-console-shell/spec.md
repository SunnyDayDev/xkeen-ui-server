# Web console shell

## Purpose

Встроенная оболочка и вход через браузер на включённом HTTPS origin.

## Requirements

### Requirement: The console is served on the configured HTTPS origin

Бинарник Go SHALL выдавать встроенную оболочку и её файлы на настроенном origin веб-сессии. Доступ к защищённому содержимому SHALL определять F03. Отсутствующий статический файл SHALL возвращать 404.

#### Scenario: An anonymous browser opens the console
- **WHEN** браузер открывает UI без действующей сессии
- **THEN** он получает оболочку и состояние входа или локальной настройки по данным сервера
- **AND** защищённые данные не запрашиваются и не отображаются

### Requirement: The console reflects real login and logout outcomes

Интерфейс SHALL использовать серверный статус, вход и выход. Отправка SHALL отображать ожидание и безопасные результаты сервера. Подтверждённый выход SHALL возвращать пользователя к входу. Рабочие страницы SHALL иметь доступную навигацию.

#### Scenario: The administrator signs in with the keyboard
- **WHEN** администратор вводит правильный пароль и отправляет форму с клавиатуры
- **THEN** браузер открывает защищённую область с текущим экраном и кнопкой выхода

#### Scenario: Server failures are actionable
- **WHEN** сервер возвращает неверный пароль, ограничение попыток либо недоступность
- **THEN** интерфейс отображает различимое сообщение и позволяет повторить действие

### Requirement: Session expiry preserves the open tab without resubmitting work

Браузер SHALL требовать повторный вход при истечении сессии и удерживать локальное состояние открытой вкладки. Успешный повторный вход SHALL возвращать управление без автоматической отправки старого запроса или черновика.

#### Scenario: An open tab returns to work after expiry
- **WHEN** открытая вкладка теряет сессию во время редактирования
- **THEN** доступ к действиям закрывается, а локальное состояние сохраняется
- **AND** после повторного входа пользователь сам решает, отправлять ли изменения
