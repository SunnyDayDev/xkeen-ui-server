# configuration-variables Specification

## Purpose

Определить однозначную сборку JSON одного элемента из шаблона и его переменных с сохранением типов, проверкой заполненности и понятными ошибками до подготовки конфигурации устройства.

## Requirements

### Requirement: Element scoped exact variable names

Сервис SHALL искать ссылку `${name}` только среди определений текущего элемента по полному имени, с учётом регистра, без обрезки пробелов и Unicode-нормализации имени. Точка SHALL быть обычным символом имени. Определение SHALL содержать непустое имя и ровно один тип из `string`, `number`, `boolean`, `object`, `array`; дефолт SHALL быть необязательным. Имя SHALL NOT содержать пробельные символы, управляющие символы, `$`, `{` или `}`. Другие символы, включая точки, дефисы, подчёркивания и буквы вне ASCII, SHALL быть допустимы. Дубликаты имён в одном элементе, неизвестный тип и значения для необъявленного имени SHALL отклоняться. Определения всех переменных элемента SHALL проверяться, даже если они не используются в JSON.

#### Scenario: Dot is part of a name

- **WHEN** шаблон содержит `{"address":"${server.address}"}`, определена string-переменная `server.address` и её значение равно `edge.example.com`
- **THEN** результат равен `{"address":"edge.example.com"}`
- **AND** объект со значением по имени `server` не заменяет определение `server.address`

#### Scenario: Element scopes and case are independent

- **WHEN** два элемента определяют `host` со значениями `one.example.com` и `two.example.com`
- **THEN** каждый получает собственное значение
- **AND** ссылка `${Host}` без отдельного определения `Host` даёт `unknown_variable`

#### Scenario: Invalid definitions or extra values

- **WHEN** переданы два определения `host`, имя `server address`, имя `a}`, пустое имя, тип `integer` или персональное значение для необъявленного `other`
- **THEN** сборка отклоняется с ошибкой соответствующего определения или значения

### Requirement: Typed whole value substitution

Сервис SHALL разбирать шаблон как JSON и заменять только строковое значение, в точности равное `${name}`, на выбранное значение объявленного типа. Подстановка SHALL работать в корне, в полях объектов и элементах массивов на любой глубине. Сервис SHALL сохранять неизвестные поля, структуру и порядок элементов массивов. JSON-тип SHALL NOT преобразовываться автоматически; числовая строка SHALL NOT становиться числом. Числа SHALL сохранять математическое значение без потери точности; конкретная запись числа, пробелы JSON и порядок ключей объекта не являются контрактом.

#### Scenario: All five value types

- **WHEN** шаблон и выбранные типизированные значения имеют следующий вид

```json
{
  "template": {
    "host": "${host}",
    "port": "${port}",
    "enabled": "${enabled}",
    "settings": "${settings}",
    "targets": "${targets}",
    "custom": {"nested": ["${port}"]}
  },
  "values": {
    "host": "edge.example.com",
    "port": 443,
    "enabled": false,
    "settings": {"network": "tcp"},
    "targets": ["example.net"]
  }
}
```

- **THEN** результат равен следующему JSON

```json
{
  "host": "edge.example.com",
  "port": 443,
  "enabled": false,
  "settings": {"network": "tcp"},
  "targets": ["example.net"],
  "custom": {"nested": [443]}
}
```

#### Scenario: Root and exact numbers

- **WHEN** корневой шаблон равен `"${n}"`, `n` имеет тип number и значение `9007199254740993`
- **THEN** результат является числом `9007199254740993` без округления
- **AND** дробное значение `0.125` также сохраняется как число без изменения значения

#### Scenario: Wrong type does not use a default

- **WHEN** number-переменная `port` имеет дефолт `443`, а персональное значение равно строке `"8443"`
- **THEN** сборка даёт `type_mismatch`, не преобразует строку и не использует дефолт

### Requirement: Missing values and defaults

Сервис SHALL считать значение незаполненным, если оно отсутствует или является строкой, пустой после удаления пробельных символов с обоих концов. `trim` SHALL использовать набор Unicode White_Space. Эта проверка SHALL предшествовать проверке объявленного типа и SHALL применяться к значению переменной целиком; она SHALL NOT удалять поля или менять вложенные строки объекта/массива. Непустые строки SHALL сохраняться без обрезки.

Незаполненное персональное значение SHALL выбирать заполненный дефолт; незаполненный строковый дефолт SHALL быть эквивалентен отсутствующему дефолту. Если оба отсутствуют, сервис SHALL возвращать `missing_value`. Наличие дефолта SHALL NOT требовать персонального значения. Заполненный дефолт SHALL проверяться независимо от наличия персонального значения. Все объявленные переменные без заполненного дефолта SHALL требовать заполненного значения, даже если ссылка на них отсутствует. `false`, `0`, `{}` и `[]` SHALL считаться заполненными значениями своих типов.

#### Scenario: Empty and whitespace strings are missing

- **WHEN** string-переменная `host` без дефолта получает `""`, `" \t\n "` или `"\u00a0"`, либо значение отсутствует
- **THEN** каждый случай даёт `missing_value`

#### Scenario: Empty personal value inherits a default

- **WHEN** у `host` есть дефолт `edge.example.com`, а персональное значение отсутствует или равно `"   "`
- **THEN** выбирается `edge.example.com`
- **AND** для number-переменной с дефолтом `443` персональная строка `"   "` также считается незаполненной и выбирает число `443`

#### Scenario: Empty default and unused required definition

- **WHEN** определена переменная `host` с дефолтом `" \t "`, персонального значения нет и шаблон не содержит ссылку на `host`
- **THEN** сборка даёт `missing_value` для `host`

#### Scenario: Nonempty values preserve content

- **WHEN** переменные соответствующих типов получают `"  edge.example.com  "`, `false`, `0`, `{}` и `[]`
- **THEN** все значения считаются заполненными и подставляются без изменения
- **AND** значение object `{"label":"   "}` считается заполненным и сохраняет вложенную строку

#### Scenario: Invalid default remains an error

- **WHEN** number-переменная имеет строковый дефолт `"443"` и корректное персональное значение `8443`
- **THEN** определение отклоняется с `type_mismatch` для дефолта

### Requirement: Null is rejected

Сервис SHALL отклонять JSON `null` во входах сборки элемента: в сыром JSON шаблона, персональных значениях и дефолтах, включая вложенные поля и элементы массивов. Ошибка SHALL иметь код `null_not_allowed`. `null` SHALL NOT означать отсутствие, удаление поля или возврат к дефолту. Строка `"null"` SHALL оставаться обычной заполненной строкой. Отсутствие переменной или дефолта SHALL представляться отсутствием записи, а не `null`.

#### Scenario: Null does not fall back

- **WHEN** у `host` задан корректный дефолт, а персональное значение равно `null`
- **THEN** сборка даёт `null_not_allowed`, не используя дефолт

#### Scenario: Null in defaults and nested values

- **WHEN** дефолт равен `null`, object-переменная содержит `{"optional":null}` или array-переменная содержит `[null]`
- **THEN** сборка отклоняется с `null_not_allowed` и местом запрещённого значения

#### Scenario: Null in the raw template

- **WHEN** сырой шаблон равен `{"optional":null}`, даже если не содержит ссылок на переменные
- **THEN** сборка отклоняется с `null_not_allowed` по пути `/optional`
- **AND** шаблон `{"optional":"null"}` сохраняет строку и проходит эту проверку

### Requirement: Literal escaping and unsupported interpolation

В строковых значениях исходного шаблона сервис SHALL обрабатывать `$$` как буквальный `$` за один проход слева направо; полученный символ SHALL NOT повторно распознаваться как начало ссылки. Поэтому `$${name}` SHALL давать буквальный `${name}` без поиска переменной. Одиночный `$`, за которым не следует `{`, SHALL сохраняться.

Корректная неэкранированная ссылка вместе с любым другим содержимым строки SHALL давать `unsupported_interpolation`. Незакрытая ссылка и имя, нарушающее правила имён, SHALL давать `invalid_reference`. Обратная косая черта SHALL NOT служить экранированием ссылок; сначала действуют обычные правила JSON. Имена ключей объекта SHALL оставаться буквальными и SHALL NOT участвовать ни в подстановке, ни в обработке `$$`.

#### Scenario: Whole and embedded literal references

- **WHEN** исходные строковые значения равны `"$${host}"`, `"https://$${host}/path"`, `"$$$$"` и `"cost $5"`
- **THEN** они становятся соответственно `"${host}"`, `"https://${host}/path"`, `"$$"` и `"cost $5"` без поиска `host`

#### Scenario: Partial interpolation is rejected

- **WHEN** строка равна `"https://${host}/path"`, `" ${host} "`, `"${host}${port}"` или `"$${literal} ${host}"`
- **THEN** сборка даёт `unsupported_interpolation`
- **AND** сервис не склеивает строку, не обрезает её до ссылки и не оставляет неэкранированную ссылку как готовый результат

#### Scenario: Malformed references and backslashes

- **WHEN** строка шаблона равна `"${}"`, `"${host"`, `"${server address}"` или `"${a{b}"`
- **THEN** сборка даёт `invalid_reference`
- **AND** JSON-строка `"\\${host}"` содержит обычную косую черту перед ссылкой и даёт `unsupported_interpolation`, а не буквальное экранирование

#### Scenario: Keys remain literal

- **WHEN** шаблон равен `{"${key}":"fixed","$${key}":"fixed"}` и определения отсутствуют
- **THEN** оба ключа и значения сохраняются без изменения

### Requirement: Substituted data is not a new template

Сервис SHALL NOT повторно интерпретировать выбранное значение или дефолт как шаблон. Строки, объекты и массивы переменных SHALL подставляться как данные, даже когда они содержат `${...}` или `$$`. Значения SHALL NOT ссылаться на другие переменные посредством повторной подстановки. Проверка запрещённого `null` SHALL сохранять силу для вложенных данных.

#### Scenario: References inside supplied data remain literal

- **WHEN** шаблон `{"text":"${text}","options":"${options}"}` получает string-значение `"${other}"` и object-значение `{"label":"$${other}"}`
- **THEN** результат равен `{"text":"${other}","options":{"label":"$${other}"}}`
- **AND** определение `other` не требуется и повторная подстановка не выполняется

### Requirement: Atomic result and safe diagnostics

Сервис SHALL возвращать либо полностью собранный JSON, либо ошибки без пригодного для применения частичного результата. Исходный шаблон, определения и персональные значения SHALL оставаться неизменными. Невалидный JSON, повторяющиеся ключи JSON-объекта и текст после завершённого JSON-значения SHALL отклоняться до сборки. Проверка SHALL NOT ограничиваться каталогом известных полей Xray.

Каждая ошибка SHALL содержать код, ID элемента и источник (`template`, `definition`, `value` или `default`), а имя переменной и путь внутри JSON — когда они известны. Для синтаксически неразбираемого JSON SHALL указываться позиция вместо недоступного структурного пути. Ошибки SHALL NOT включать значения переменных, дефолты или сырой JSON. Порядок ошибок и полнота их накопления не являются контрактом; как минимум одна конкретная причина SHALL быть доступна.

#### Scenario: Unknown reference has a location

- **WHEN** элемент `outbound-demo` содержит `{"settings":{"address":"${missing}"}}` без определения `missing`
- **THEN** сборка даёт `unknown_variable`, ID `outbound-demo`, источник `template`, имя `missing` и путь `/settings/address`
- **AND** частичный результат не возвращается

#### Scenario: Invalid JSON input

- **WHEN** вход содержит незавершённый JSON, два корневых значения или повторяющийся ключ объекта
- **THEN** сервис отклоняет вход, не выбирая молча одно из значений

#### Scenario: Inputs and secrets are preserved

- **WHEN** сборка элемента с несколькими значениями завершается ошибкой типа в одном из них
- **THEN** входные данные остаются прежними, результат отсутствует, диагностика сообщает место и ожидаемый тип без вывода фактических значений

### Requirement: Substitution from prepared element values

Сервис SHALL предоставлять отдельную операцию подстановки, принимающую ID элемента, сырой JSON шаблона и подготовленный набор значений по именам только этого элемента. Подготовленный набор SHALL содержать уже выбранные значения: строки, числа, boolean, объекты или массивы, без определений и дефолтов. Операция SHALL использовать JSON-тип каждого переданного значения без автоматического преобразования и SHALL NOT самостоятельно выбирать дефолт или искать значения в других элементах.

Для шаблона с корректными целыми ссылками `${name}` и постоянными значениями операция SHALL подставлять значения в корне, полях объектов и элементах массивов, сохраняя структуру, неизвестные поля и порядок массивов. Имя SHALL сравниваться целиком, с учётом регистра, без обрезки и нормализации; точка SHALL оставаться частью имени. Числа как шаблона, так и подготовленных значений SHALL сохранять математическое значение без потери точности; форматирование и порядок ключей объектов не являются контрактом.

Подготовка набора и проверка полной конфигурации остаются отдельными операциями. Успех этого шага SHALL NOT означать выполнение всех требований полной сборки: проверки определений, заполненности, null и полного синтаксиса сохраняют силу на границе полной сборки. Гарантии этого шага для подготовленных входов не вводят разрешение на запрещённые полной сборкой данные.

#### Scenario: Prepared values retain all five types

- **WHEN** шаблон и подготовленные значения равны

```json
{
  "template": {
    "host": "${host}",
    "port": "${port}",
    "enabled": "${enabled}",
    "options": "${options}",
    "targets": "${targets}"
  },
  "values": {
    "host": "edge.example.com",
    "port": 443,
    "enabled": false,
    "options": {"network": "tcp"},
    "targets": ["example.net"]
  }
}
```

- **THEN** результат равен

```json
{
  "host": "edge.example.com",
  "port": 443,
  "enabled": false,
  "options": {"network": "tcp"},
  "targets": ["example.net"]
}
```

#### Scenario: Root substitution preserves the supplied type

- **WHEN** корневой шаблон `"${value}"` получает поочерёдно `"443"`, `0`, `false`, `{}` и `[]`
- **THEN** результат в каждом случае равен переданному значению с его JSON-типом
- **AND** строка `"443"` остаётся строкой, а `0`, `false` и пустые контейнеры не исчезают

#### Scenario: Nested references and unknown fields are preserved

- **WHEN** шаблон равен `{"custom":{"items":[{"port":"${port}"},"fixed","${port}"]},"extension":true}` и `port` равен `443`
- **THEN** результат равен `{"custom":{"items":[{"port":443},"fixed",443]},"extension":true}`
- **AND** неизвестные поля, постоянные значения и порядок массива сохраняются

#### Scenario: Exact names and element isolation

- **WHEN** два отдельных вызова используют шаблон `{"address":"${server.address}"}` и собственные наборы со значениями `one.example.com` и `two.example.com` для имени `server.address`
- **THEN** каждый результат содержит значение своего набора
- **AND** наличие только имени `server` с объектом `{"address":"one.example.com"}` не разрешает ссылку `server.address`
- **AND** наличие только имени `Server.Address` также не разрешает ссылку `server.address`

#### Scenario: Numbers in templates and values remain exact

- **WHEN** шаблон равен `{"constant":9007199254740993,"selected":"${n}"}` и `n` равен `9007199254740993`
- **THEN** оба числа в результате равны `9007199254740993`, без округления
- **AND** подстановка `0.12345678901234567890123456789` и `1e400` также сохраняет математическое значение

#### Scenario: Constant template needs no values

- **WHEN** корректный шаблон без ссылок, например `{"custom":[0,false,"fixed",{},[]]}`, получает пустой набор
- **THEN** результат семантически равен шаблону

### Requirement: Prepared substitution rejects invalid JSON inputs

Операция подстановки SHALL разбирать шаблон и каждое подготовленное значение как ровно одно JSON-значение. Неправильный или незавершённый JSON и лишний текст после значения SHALL приводить к `invalid_json`; повторяющиеся ключи объекта на любой глубине SHALL приводить к `duplicate_json_key`. Сравнение ключей SHALL выполняться после JSON-декодирования строк. Проверка SHALL охватывать и переданные значения, которые не используются в шаблоне. Одинаковые ключи в разных объектах SHALL быть допустимы.

#### Scenario: Invalid template has a safe position

- **WHEN** шаблон содержит незавершённый объект, два корневых значения или текст после завершённого значения
- **THEN** операция возвращает `invalid_json`, ID элемента, источник `template` и позицию ошибки без сырого JSON
- **AND** результат отсутствует

#### Scenario: Invalid supplied value is identified

- **WHEN** подготовленное значение `options` содержит неправильный JSON или два корневых значения, независимо от наличия ссылки на `options`
- **THEN** операция возвращает `invalid_json`, ID элемента, источник `value`, имя `options` и позицию ошибки
- **AND** результат отсутствует

#### Scenario: Duplicate keys are detected after decoding

- **WHEN** шаблон или подготовленное значение содержит `{"nested":{"a":1,"\u0061":2}}`
- **THEN** операция возвращает `duplicate_json_key` по пути `/nested/a`, с ID элемента и соответствующим источником
- **AND** для подготовленного значения указывается его имя
- **AND** результат отсутствует

#### Scenario: Keys in separate objects do not collide

- **WHEN** шаблон равен `{"first":{"a":1},"second":{"a":2}}` и набор пуст
- **THEN** операция успешно сохраняет оба объекта

### Requirement: Prepared substitution returns an atomic result and located errors

Если корректная целая ссылка отсутствует в подготовленном наборе, операция SHALL возвращать `unknown_variable`, ID элемента, источник `template`, точное имя и путь к ссылке. Путь SHALL использовать JSON Pointer: `~` экранируется как `~0`, `/` как `~1`, корень обозначается пустой строкой, элементы массива — индексами от нуля.

Операция SHALL возвращать либо новый JSON-результат без ошибок, либо как минимум одну конкретную диагностику и отсутствие результата. Шаблон и набор значений SHALL оставаться неизменными при успехе и ошибке; изменение возвращённого результата после успеха SHALL NOT менять входы. Диагностика SHALL NOT включать исходные значения или сырой JSON. Порядок и полнота накопления независимых ошибок не являются контрактом.

#### Scenario: Unknown variable identifies a nested reference

- **WHEN** элемент `outbound-demo` содержит `{"settings":{"address":"${missing}"}}` и набор не содержит `missing`
- **THEN** возвращается `unknown_variable`, ID `outbound-demo`, источник `template`, имя `missing` и путь `/settings/address`
- **AND** результат отсутствует

#### Scenario: Root and escaped paths locate unknown references

- **WHEN** ссылка `${missing}` находится в корне JSON либо в шаблоне `{"a/b~c":["${missing}"]}`
- **THEN** ошибка имеет соответственно пустой путь либо `/a~1b~0c/0`

#### Scenario: Error preserves all inputs and does not disclose data

- **WHEN** шаблон содержит известную и неизвестную целые ссылки, а подготовленный набор содержит строковое значение `demo-private-value`
- **THEN** операция возвращает ошибку неизвестной ссылки и не возвращает частичный JSON
- **AND** шаблон и все подготовленные значения остаются прежними
- **AND** диагностика не содержит `demo-private-value` или текст шаблона

#### Scenario: Successful result does not share writable input data

- **WHEN** успешная подстановка завершена и потребитель изменяет полученный результат
- **THEN** исходный шаблон и подготовленные значения остаются прежними
