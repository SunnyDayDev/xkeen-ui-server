## Purpose

Владелец меняет отображаемое имя точного роутера, сохраняя техническую идентичность устройства.

## Requirements

### Requirement: The console edits only the displayed router name

Владелец SHALL иметь возможность изменить отображаемое имя подтверждённого видимого роутера по правилам имени #190. Условное сохранение SHALL учитывать точный RouterID, исходную версию и действующую сессию с защитой изменения.

#### Scenario: An exact saved name appears in the overview and details

- **WHEN** владелец подтверждает допустимое имя для текущего снимка
- **THEN** обзор и карточка отображают сохранённое имя без изменения ID, профиля, настроек, ключа, контакта, истории и ревизий

#### Scenario: Another change or invalid input prevents saving

- **WHEN** введено недопустимое имя, изменилось исходное состояние или допуск
- **THEN** сервер отклоняет сохранение
- **AND** форма показывает причину и сохраняет введённый текст в текущем контексте

#### Scenario: The result cannot be confirmed

- **WHEN** ответ на явное сохранение неизвестен
- **THEN** владелец может явно прочитать текущее имя без вывода об исходе прошлого запроса
- **AND** интерфейс не повторяет запись автоматически
