# web-router-inbound-state Specification

## Purpose

Изменять состояние одного входа роутера в авторизованной браузерной области центрального сервера.

## Requirements

### Requirement: Effective routing dependencies guard one inbound change

Редактор SHALL показывать зависимости выбранного входа. Сервер SHALL отклонять выключение или удаление используемого входа по действующим правилам B10. Успешная запись SHALL менять только выбранный черновик.

#### Scenario: An effective rule protects a referenced inbound
- **WHEN** хотя бы одно действующее правило использует итоговый вход, который владелец пытается выключить или удалить
- **THEN** сохранение отклоняется, интерфейс показывает известные зависимые правила

#### Scenario: Unused inbound changes stay local to the router
- **WHEN** вход свободен и разрешённое действие проходит условную запись
- **THEN** выбранный вход меняется только в черновике данного роутера

#### Scenario: An exact accepted basis protects the decision
- **WHEN** зависимость неоднозначна, основание порядка неизвестно или использованная версия изменилась после чтения
- **THEN** запись отклоняется без частичного изменения, интерфейс позволяет перечитать проверяемые настройки

#### Scenario: Router-local removal preserves shared data
- **WHEN** владелец подтверждает удаление свободного общего входа
- **THEN** у этого роутера сохраняется исключение, общий исходный элемент и персональный текст сохраняются

#### Scenario: A local inbound can be removed entirely
- **WHEN** владелец подтверждает удаление свободного локального входа
- **THEN** удаляется только локальная запись и её отметка выключения, если она была
