## Why

Сторонним программам нужен отдельный стабильный интерфейс управления. [F19 #104](https://github.com/SunnyDayDev/xkeen-ui-server/issues/104).

## What Changes

- Зафиксировать отдельную границу HTTPS, доступность внешнего API и независимое требование авторизации.
- Определить начальные положения и жизненный цикл учётных данных после решения владельца. Текущие варианты перечислены в design.
- Описать первые операции шаблона и границы F20–F22. HTTP-адаптеры используют общие прикладные сценарии управления.
- Подготовить машиночитаемое описание первого среза. F19 планирует контракт, реализация идёт в последующих issue.

## Capabilities

### New Capabilities

- `external-management-api` — допуск и первая область операций внешнего программного канала.

## Impact

Отдельный HTTP-адаптер и эксплуатационные настройки внешней области. Существующие агентские полномочия D02 и браузерный доступ F03 сохраняют свои области.
