## Context

F09 создаёт подтверждённое назначение, F10 показывает ожидающее подключение. После первого принятого контакта D06 роутер становится наблюдаемым в обзоре. Отключение связи и состояние применения E08 независимы от регистрации. G05 хранит временную видимость отдельно.

## Decisions

1. Открывать список в существующем обзоре `/ui/` рядом с действием подключения F09. Выбор строки сохраняет точный RouterID в параметре `routerId`; боковая панель использует запись того же снимка. По прямой ссылке, кнопке «Назад» и после возврата читается текущий список. Закрытие панели возвращает фокус к строке, если она ещё видима. Узкий экран показывает панель без горизонтальной прокрутки.
2. Защищённый `GET /ui/v1/routers` читает действующую F03-сессию и полный список в одной read-транзакции SQLite. Переиспользовать выборку наблюдаемых и видимых ID G05 и расчёт D06 для одного времени сервера. Читать только подтверждённые назначения с записью контакта; не включать временно скрытые. Вызов не продлевает сессию, не вызывает heartbeat и не меняет документы публикации. Миграция не требуется.
3. Ответ содержит точный ID, имя активных настроек с fallback к ID, активный шаблон, серверный статус связи, желаемую и последнюю подтверждённую применённую ревизии и состояние runtime из D06/E08. Ревизии передаются каноническими десятичными строками. Серверный порог «нет связи» наступает в 180 секунд включительно. Исторический успех и новый неизвестный runtime показываются вместе. В списке и панели нет конфигов, токенов, хэшей, курсоров и содержимого диагностики.
4. Обновлять снимок чтением при открытии и возврате фокуса и периодически в видимой вкладке. Устаревший ответ не восстанавливает данные после выхода или смены области. Ошибка чтения отличается от успешного пустого списка. Если открытая строка становится скрытой, её прежние сведения убираются. Действия изменения роутера, статусов, ключей и видимости принадлежат последующим задачам.
5. Обновить обзор 00 и боковую панель через Pencil. Проверить ожидание, пустой список, сетевую ошибку, связь/применение, отзыв ключа без исчезновения строки, неизвестный runtime и узкую компоновку до UI-кода.

## Risks / Trade-offs

Одно чтение согласует данные панели и списка. Только принятые контакты определяют наблюдение; регистрация и выдача приглашения сохраняют отдельный путь F10 для ожидающих устройств.
