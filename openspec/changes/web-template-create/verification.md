# Проверка F06

- Девять состояний Pencil независимо проверены до кода. Совместимые копии поверх F20 используют IqwxF, JY3pN, EUCJJ, Shiyd, i68NWx, SeM3E, n3aLw1, rbO3r, b7Gef. Рендеры списка и настроек сохранены. Форма визуально сверена с Chrome на 1080 и 360 px.
- Red: тест SQLite зафиксировал отсутствие запроектированного writer. Тест HTTP воспроизвёл прежний 405. Тест Chrome дошёл до отсутствующей кнопки после штатного входа. Отдельная браузерная регрессия воспроизвела игнорирование смены полномочия в другой вкладке при незавершённой отправке.
- Green: реальная SQLite допускает только одну из двух конкурентных вставок, сохраняет предыдущий изменённый черновик при конфликте, обновляет активность только при коммите и блокирует запись при отзыве и точных границах времени после получения writer.
- HTTPS процесс проверил 403 при неверном CSRF, 201 для точного ID с версией 1, 409 при повторе, 401 после локального сброса и сохранность записи после перезапуска. Сценарии конверта проверили дубликаты ключей, ошибочные значения, лимит, origin и no-store.
- Chrome через штатный Go HTTPS и SQLite проверил создание, показ занятого состояния, ошибку перечитывания и ручной повтор, дубликат, неизвестный результат, истечение, восстановление поля через вход и запоздалый успешный ответ после смены маршрута или полномочия. Запись после повторного входа остаётся явным действием.
- Воспроизводимая Vite-сборка на Node 26.5.0, Go test/race и vet, Linux AMD64/ARM64 и git diff --check прошли. Проверка реального HTTPS в изолированном Entware aarch64-k3.10 под LinuxKit 7.0.14 с лимитом 256 МиБ прошла с пиком 186949632 байта и oom_kill 0.
