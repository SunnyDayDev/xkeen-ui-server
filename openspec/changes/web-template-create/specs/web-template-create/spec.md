## Purpose

Создавать пустой сохраняемый черновик шаблона по выбранному администратором стабильному идентификатору.

## ADDED Requirements

### Requirement: Создание пустого черновика по точному ID

Сервис SHALL принимать POST /ui/v1/templates с одним строковым полем id через настроенный HTTPS origin. Допускается непустой ID в UTF-8 по правилам C02. Регистр и последовательность символов сохраняются. Результат успешного создания — 201, точный id и версия "1". Шаблон SHALL сохраняться без элементов, публикации или применения.

#### Scenario: Новый уникальный ID

- **WHEN** авторизованный администратор подтверждает создание с новым допустимым ID
- **THEN** выполняется одна вставка пустого черновика с этим ID и версией 1
- **AND** последующее чтение списка в том числе после перезапуска содержит этот ID и версию

#### Scenario: Дубликат

- **WHEN** такой же ID уже существует
- **THEN** сервер отвечает 409 template_exists
- **AND** черновик и его версия сохраняются без изменений, и время бездействия не продлевается

#### Scenario: Недопустимый запрос

- **WHEN** конверт не является единственным JSON-объектом с допустимым id либо содержит повторяющиеся или неизвестные поля
- **THEN** сервер отвечает 400 invalid_request и не создаёт запись

#### Scenario: Неподдерживаемый тип или слишком большое тело

- **WHEN** Content-Type не равен application/json или JSON-конверт превышает 8 КиБ
- **THEN** сервер отвечает 415 либо 413 соответственно и не создаёт запись

### Requirement: Запись требует действующей браузерной сессии

Создание SHALL требовать соответствующие HTTPS origin, браузерную session cookie и X-CSRF-Token. Сессия должна действовать в момент принятия записи. Успешное создание считается явным действием и обновляет время бездействия в пределах абсолютного срока.

#### Scenario: Чужой origin или неверный CSRF

- **WHEN** origin не совпадает либо токен действий неверен или отсутствует
- **THEN** сервер не создаёт запись и отвечает 403 invalid_origin либо invalid_csrf

#### Scenario: Сессия отозвана или истекла до записи

- **WHEN** отзыв сессии опережает запись либо на момент допуска достигнут предел бездействия или абсолютный срок
- **THEN** сервер отвечает 401 signed_out и не создаёт запись

### Requirement: Форма создания в списке шаблонов

Раздел «Шаблоны» SHALL показывать «Создать шаблон» и открывать форму с полем «Идентификатор шаблона». Создание происходит после явной отправки формы. Пока результат ожидается, форма не отправляется повторно.

#### Scenario: Создание удалось

- **WHEN** сервер подтвердил создание черновика
- **THEN** список перечитывается и показывает новый ID с версией 1
- **AND** если перечитать нельзя, раздел показывает подтверждение создания и предлагает повторить чтение

#### Scenario: Конфликт или неизвестный результат

- **WHEN** сервер сообщает дубликат либо клиенту не удалось подтвердить результат записи
- **THEN** форма удерживает введённое значение и показывает применимое сообщение
- **AND** значение не отправляется автоматически

#### Scenario: Сессия истекла при отправке

- **WHEN** открытая форма теряет браузерную сессию
- **THEN** консоль скрывает форму и показывает вход
- **AND** успешный вход в той же вкладке возвращает форму с введённым ID и ждёт явного подтверждения


#### Scenario: Ответ получен для закрытой формы или прежней сессии

- **WHEN** клиент получает поздний ответ после перехода из раздела, начала выхода или смены сессии
- **THEN** ответ не меняет текущий раздел, сессию или другую форму
- **AND** клиент не повторяет запись автоматически, а последующее чтение показывает фактически сохранённый результат
