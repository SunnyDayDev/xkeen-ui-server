## Why

Владелец временно скрывает роутер из обзора согласно согласованному сценарию и G04/G05. Нужен защищённый шаг в карточке. [Issue #237](https://github.com/SunnyDayDev/xkeen-ui-server/issues/237).

## What Changes

- В карточке доступны отдельное действие и подтверждение. Пояснение описывает возврат при следующем допустимом контакте.
- Условная запись привязана к выбранному роутеру и текущей веб-сессии. После подтверждения обзор перечитывается.
- Если результат неизвестен, интерфейс предлагает явно проверить видимость перед повтором.

## Capabilities

### New Capabilities

- `web-router-hide`: временное скрытие из карточки через сессию владельца.

### Modified Capabilities

Нет.

## Impact

Веб-консоль, F03, API консоли, G05 и синтетический сценарий Chromium. Операция повторно использует механизм #191 после приёмки. Переименование ведётся в #238.
