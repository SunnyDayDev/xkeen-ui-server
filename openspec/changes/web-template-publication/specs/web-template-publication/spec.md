## Purpose

Показать последствия и подтвердить общую публикацию в авторизованной браузерной области центрального сервера.

## ADDED Requirements

### Requirement: A shared preview and explicit confirmation govern one atomic publication

Оператор SHALL увидеть предусмотренный общий результат и все действующие назначения, включая недоступные устройства. Публикация SHALL требовать отдельного явного подтверждения точного актуального предпросмотра и сохранять изменения одним атомарным C07 действием.

#### Scenario: Preview includes offline routers and does not publish
- **WHEN** владелец готовит общий предпросмотр шаблона с подключёнными и недоступными роутерами
- **THEN** отображаются изменения по полному составу и оценка способа применения; желаемые ревизии остаются прежними

#### Scenario: A previously previewed group changes before confirmation
- **WHEN** меняется шаблон, использованное поколение, желаемая ревизия, состав либо результат закреплённого Xray
- **THEN** подтверждение отклоняется без частичной записи и требует нового предпросмотра

#### Scenario: An owner confirms a current complete preview
- **WHEN** все реальные кандидаты прошли проверку и условия предпросмотра остаются актуальными
- **THEN** C07 атомарно сохраняет общий снимок и необходимые желаемые ревизии; применённость определяется отдельно по агенту
