## Decisions

Проверять независимый F20 permit, существование точного подтверждённого роутера и сохранённой desired ревизии одним read-only transaction. Прямой запрос известного ID следует G05: временное скрытие влияет на список, а доступ к существующему точному устройству сохраняется. Формат отдаёт routerId, revision, latestDesiredRevision, при наличии historicallyAppliedRevision, contact, runtime, result и допускаемые stage/code для точного сохранённого failed отчёта. Номера передаются строками.

Сопоставить evidence с точным номером по D06/E08. Если запрошенный номер совпадает с текущим точно подтверждённым applied и runtime доказан, результат applied. Сохранённый applying или failed показывается только для собственного номера, включая distinct rollback_failed и runtime_unknown. Подтверждённое историческое применение отображается отдельно от неопределённого действующего runtime. При отсутствии точного свидетельства результат unknown, включая пропущенные сообщением или устаревшие ревизии. D06 хранит один последний отчёт, текущую историческую applied и неопределённость. Эта операция не создаёт историю. Не возвращать sequence, снимок каталога, рабочие ключи и текст Xray. Ошибки no-store.

## Risks / Trade-offs

F20 действует по явной настройке владельца. Точные значения и цели проверяются на момент чтения или транзакции записи.
