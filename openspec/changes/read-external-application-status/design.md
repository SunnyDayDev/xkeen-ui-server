## Decisions

Проверять независимый F20 permit, существование точного подтверждённого роутера и сохранённой desired ревизии одним read-only transaction. Этот F20 маршрут разрешает прямой запрос известного ID подтверждённого устройства. Маркер временного скрытия G05 меняет состав списка. Формат отдаёт routerId, revision, latestDesiredRevision, при наличии historicallyAppliedRevision, contact, runtime, result и допускаемые stage/code для точного сохранённого failed отчёта. Номера передаются строками.

Сопоставить evidence с точным номером по D06/E08. Latest applying или failed по точному номеру описывает последнюю попытку и имеет приоритет над прежним applied того же номера. Ошибки rollback_failed и runtime_unknown дают failed и отдельно runtime unknown. Иначе результат applied требует совпадения с точно подтверждённым applied и verified runtime. Подтверждённое историческое применение отображается отдельно от неопределённого действующего runtime. При отсутствии точного свидетельства результат unknown, включая пропущенные сообщением или устаревшие ревизии. D06 хранит один последний отчёт, текущую историческую applied и неопределённость. Эта операция не создаёт историю. Не возвращать sequence, снимок каталога, рабочие ключи и текст Xray. Ошибки no-store.

## Risks / Trade-offs

F20 действует по явной настройке владельца. Точные значения и цели проверяются на момент чтения или транзакции записи.
