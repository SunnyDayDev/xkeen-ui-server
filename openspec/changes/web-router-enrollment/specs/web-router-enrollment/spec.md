## Purpose

Экран подключения показывает параметры агента и управляет одноразовым приглашением подготовленного устройства.

## ADDED Requirements

### Requirement: Enrollment parameters are available only for a prepared router

Только владелец SHALL видеть доступные параметры подготовленного роутера и отдельно выпускать приглашение D02. Полный токен SHALL возвращаться только при успешном выпуске.

#### Scenario: A new invitation never implies application
- **WHEN** владелец выпустил первое приглашение для роутера с первой желаемой ревизией
- **THEN** экран показывает срок и ожидание контакта, сохраняя различие регистрации и применения

#### Scenario: Reading an existing invitation cannot reveal its secret
- **WHEN** страница перезагружена либо выданное приглашение истекло или заменено
- **THEN** доступны безопасные метаданные и допустимое явное действие, прежний секрет не раскрывается
