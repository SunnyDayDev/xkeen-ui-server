## Context

Экран подключения показывает параметры агента и управляет одноразовым приглашением подготовленного устройства. Используются D02, D03, D04 и F09.

## Decisions

Публичный HTTPS origin агента — доверенная конфигурация развёртывания, без вывода из Host/forwarded/браузерного origin. Используется актуальный путь D04 с файлом invitation 0600; UI не подставляет секрет в URL, аргументы процесса и команды, копируемые в журналы. Только успешный POST выдачи показывает полное приглашение в памяти текущей страницы; время и безопасное состояние читаются отдельно. История не содержит исходного рабочего ключа. Авторизация владельца проверяется в транзакции D02, замена соперничает с погашением под тем же writer. После принятой первой регистрации восстановление идёт по соответствующей явной роли D02, без повторного создания роутера; точный объём UI восстановления согласуется отдельно. Экран Pencil 12, удалить старую ссылку на пакеты и показать ожидающее состояние.

## Risks / Trade-offs

Сетевой сбой не подтверждает результат. Пользователь сохраняет редактируемое состояние текущей вкладки, а серверная операция сверяется по устойчивому ID. Перед разработкой уточнить сквозные состояния в Pencil и передать результаты на независимое ревью.
