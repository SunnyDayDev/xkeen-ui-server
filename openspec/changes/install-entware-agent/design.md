## Границы

POSIX shell загружает только закреплённый manifest и имена выпуска. HTTPS через curl с ограничением протокола редиректов, локальное зеркало с отдельной CA. Строгий разбор списка SHA-256, единичные записи известных имён, ограничения размера, прямое сравнение проверенных значений. Приватный staging создаётся в защищённом каталоге. Helper скачивается как часть выпуска и исполняется только после сверки.

Linux ARM64 helper фиксирует константные производственные пути и разделяет install/lifecycle. Под защищённым lock проверяет корень, symlinks, права и состояние. Профиль со строго определёнными полями, без `source` или интерпретации произвольных команд. Подготовка полного поколения и подпись экземпляра локальной службы сохраняются через fsync и атомарную публикацию. Предыдущая установка до G14 возвращает ошибку, существующие ключи/приглашения никогда не перезаписываются.

Для первого запуска агент получает invite из владельческого файла с режимом 0600, после проверки открытого дескриптора. Утилита подготавливает рабочую копию на имя `invitation` с режимом 0600 и UID агента. Аргументы и логи не содержат bearer. Пользователь непривилегированный и отдельный. Состояние из неготовой первой попытки остаётся для точного retry. Тест использует реальный TLS и агентский сигнал `agent authenticated` до объявления готовности.

Управляющий helper запускает только закреплённый бинарник, а init.d регистрирует ограниченный интерфейс start/stop/status. Для остановки проверяются PID, start tick, UID и идентичность бинарника с устойчивым дескриптором процесса либо эквивалентной гарантией. Сведения из изменяемой агентом области не дают полномочия остановить иной процесс. Привилегированное окружение не наследует потенциально изменяемые команды или профили.

G13 предоставляет одну транспортную службу. Управляемый профиль не объявляется готовым, пока G18 не проверит нормальный provisioning E08 и барьер. Неподдерживаемые роли блокируются явно.
