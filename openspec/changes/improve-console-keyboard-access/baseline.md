# Первая поставка проверки консоли

Матрица относится к принятым экранам на базе #205. Браузерный сценарий запускает Chromium, штатный HTTPS-сервер с SQLite и синтетическими данными. Для сценариев назначения и подключения нужны изолированный проверяющий процесс Xray и агент.

| Сценарий | Существующая проверка | Осталось для итоговой приёмки |
| --- | --- | --- |
| Вход, выход, повторный вход | `web/browser.mjs` проверяет Enter, сохранение буфера и возврат фокуса. Узкая компоновка на 360 px | Полный цикл Tab и Shift+Tab на 320 px |
| Список, новый шаблон | `web/browser.mjs` проверяет навигацию, создание и узкий список | Клавиатурный маршрут от списка через отправку и конфликт ID |
| Общий JSON, определения, добавление элемента | `web/template-editor-browser.mjs`, `web/template-variables-browser.mjs` проверяют редактирование, Enter и компоновку на 390 px | Последовательность фокуса вокруг смены состояния и длинный ввод на 320 px |
| Копирование шаблона | `web/template-copy-browser.mjs` проверяет конфликт источника на 320 px и продолжение клавиатурой, а также потерянный ответ | Повтор на итоговой базе |
| Первое назначение и приглашение | `web/browser.mjs`, `web/router-enrollment-browser.mjs` проверяют настоящее назначение, одноразовую выдачу и узкий экран на 360 px | Клавиатурные переходы к отзыву, показу и скрытию |
| Обзор роутеров и рабочий ключ | `web/router-overview-browser.mjs`, `web/agent-keys-browser.mjs` проверяют смену выбранного роутера, потерю связи и ключевые операции | Порядок при открытой боковой панели на 320 px и при замене действий |
| Персональные значения и собственный JSON | `web/router-variable-browser.mjs`, `web/router-replacement-browser.mjs` проверяют повторный вход и узкий путь на 390 px | Клавиатурный маршрут с ошибкой и восстановлением на 320 px |
| Настройки доступа к API | `web/external-access-browser.mjs` проверяет повторный вход и действия с доступом | Порядок фокуса в подтверждениях и просмотр срока/секрета на 320 px |

В старой версии после отправки формы копирования через Tab и Enter ответ об изменении источника убирал кнопку отправки. Активным становился `body`. В новой версии при потере фокуса он переходит к «Перечитать». Табуляция ведёт к «Отмена», Shift+Tab возвращает к «Перечитать». После явного перечитывания сохранённый ввод снова получает фокус. После неподтверждённой выдачи фокус получает «Проверить список», после обнаружения строки — «Открыть шаблон». Фокус, который владелец уже перевёл на другое действие, сохраняется. Макет Pencil `V9wepC` и `CUsXJ` (320 px).

Сначала соберите веб-активы командой `npm --prefix web run build` и штатные сервер и агент из `cmd/`. Укажите путь к Chromium, этим бинарникам и сокету изолированного валидатора в `CHROME_EXECUTABLE`, `XKEEN_TEST_SERVER_BINARY`, `XKEEN_TEST_AGENT_BINARY` и `XKEEN_TEST_F09_VALIDATOR_SOCKET`. Затем выполните `npm --prefix web run test:browser` с [синтетическими HTTPS-фикстурами](../../../web/browser.mjs). Сценарий сравнивает ширину документа с 320 px, активное действие и `:focus-visible`. Без исправления сценарий останавливается в ожидании фокуса на кнопке «Перечитать».
