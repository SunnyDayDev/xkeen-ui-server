# Повторная проверка принятых экранов

Начата на принятой сборке с F18 и G08. Команды запуска и синтетические данные описаны в [первой проверке](baseline.md).

| Экран | Проверка |
| --- | --- |
| Вход | На 320 px состояние первичной настройки подтверждается Enter. Tab ведёт от пароля к кнопке входа с видимым фокусом, Shift+Tab обратно. После ошибки правильный ввод отправляется без мыши. |
| Создание шаблона | На 320 px Enter открывает форму. Tab ведёт от точного ID к кнопке создания с видимым фокусом. Дубликат оставляет текст и показывает ошибку. |
| Общая публикация F18 | Принятый сценарий Chromium использует Enter для предпросмотра, перехода к отдельному подтверждению и явного подтверждения. Он проверяет узкие 320 px, участника без связи, устаревший план и ручное чтение после потери ответа. |
| Общие исключения G08 | С клавиатуры доступны добавление переменной, включение дефолта, проверка и сохранение. На 320 px конфликт двух вкладок сохраняет ввод. В исходной сборке Chromium воспроизвёл потерю фокуса после скрытия кнопки «Сохранить». После исправления фокус получает «Перечитать», Tab переходит к «К шаблону», Shift+Tab возвращает к «Перечитать». Явное перечитывание возвращает фокус к «Сохранить». Проверяются активный элемент и видимый фокус. Макеты Pencil Zaexi и fESn2 просмотрены независимо. |
| Настройки доступа F20 | На 320 px Space переключает флаги, Tab ведёт к сохранению. Исходная сборка теряла фокус при скрытии токена. Теперь после скрытия выбран «Заменить токен», после открытия подтверждения — «Отмена». Shift+Tab ведёт к «Подтвердить замену» и только отдельный Enter выполняет её. Истечение сессии по-прежнему очищает показ токена. Макеты Fq0sT и g3qyxy просмотрены независимо. |
| Подключение F10 и рабочий ключ | Enter проводит выдачу, явную замену, перечитывание, отзыв и восстановление. На 320 px приглашение не расширяет документ. Сохранены проверки потери ответа, поздней выдачи и реального принятия ключа агентом. |
| Персональные переменные F12 и свой JSON F13 | На 320 px Space переключает наследование, Enter сохраняет и перечитывает. Ошибка JSON, конфликт и повторный вход сохраняют введённый текст. Явные отмена и подтверждение возврата или сброса доступны с клавиатуры. |
| Скрытие роутера | На 320 px Enter открывает подтверждение и отменяет с восстановлением фокуса. Shift+Tab ведёт к отдельному подтверждению, затем фокус переходит на обзор. Потеря ответа и повторный вход требуют явного чтения. Допустимый heartbeat возвращает ту же строку без открытия карточки. |
| Изменение имени роутера | На 320 px Enter открывает форму и даёт фокус полю. Tab ведёт к отдельному сохранению. Отмена возвращает фокус к исходному действию. После конфликта и потери ответа доступно явное чтение с сохранением ввода. |
| JSON и определения общего элемента F07/F08 | Enter открывает, сохраняет и перечитывает. На 320 px проверены редактор с конфликтом, точный исходник, ошибочный JSON и возврат после повторного входа. |
| Обзор F11 и локальное правило F14 | На 320 px Enter открывает и закрывает карточку с возвратом фокуса. Локальное правило доступно для добавления, отмены и исправления после изменения порядка. |
| Персональные исключения | На 320 px Space включает персональное значение, Enter подтверждает замену, возврат к значениям и явный сброс. |
| Копирование шаблона | На 320 px Tab и Enter отправляют форму. При конфликте кнопка «Перечитать» получает видимый фокус. После перечитывания фокус возвращается к сохранённому значению. Неопределённый исход разрешается явным чтением списка. |
| Порядок F15, входы F16 и файлы F17 | На 320 px Enter перемещает правила и открывает возврат порядка, выключает вход и проходит раздельные отмену и удаление. После удаления последнего входа фокус получает «К роутеру». Enter открывает файлы, переключает источник и скачивает ровно показанные байты. |
| Смена профиля G03 | Проверка штатного Chromium открывает маршрут с Enter, нативно выбирает профиль клавишей и на 320 px проходит предпросмотр, отмену и отдельное подтверждение. Видимый фокус сначала получает «Отмена». Shift+Tab ведёт к «Подтвердить смену», а возврат из формы восстанавливает фокус на «Сменить профиль». Перед пересчётом прежний профиль сохраняется. Обновление принятого шаблона требует нового предпросмотра, а неясный результат и просроченная сессия требуют отдельного чтения. |
