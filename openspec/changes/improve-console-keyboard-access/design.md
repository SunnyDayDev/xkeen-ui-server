## Decisions

1. Инвентарь проверок включает первоначальный вход, ошибку и повтор после истечения, обзор/панель, шаблоны и создание/копирование, редакторы JSON и переменных, подготовку/приглашение и рабочий ключ, настройки внешнего доступа. До окончательной приёмки добавить F14–F18, смену профиля G03 и исключения G08.
2. Выполнить маршруты клавишами Tab, Shift+Tab, Enter, Space и встроенными клавишами полей. Фокус должен быть заметен. После смены экрана, закрытия панели и явной загрузки фокус остаётся в логической области работы. Ошибка и новый путь продолжения доступны без мыши. Истечение сессии сохраняет разрешённый буфер и исключает повтор отправки.
3. Проверить ширины 320 и 1080 пикселей. Страница не прокручивается по горизонтали, длинные значения остаются читаемы, редактор может иметь собственную прокрутку. Сопоставить последовательность фокуса с размещением на каждой ширине.
4. Сначала подтвердить состояние принятой сборки настоящими браузером, HTTPS и SQLite. Для выявленного поведения обновить Pencil до продуктового теста и исправления. Результаты записать в воспроизводимый браузерный сценарий. Синтетические проверки, использующие Xray/агента, выполняются только на изолированном стенде.

## Risks / Trade-offs

Доступность не сводится к длине списка клавиш. Проверки включают семантические ошибки и выполнение каждого основного действия, а состояние последующих экранов учитывается отдельно при окончательной приёмке.
