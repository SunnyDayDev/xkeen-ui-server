PATCH /api/v1/templates/item/definitions?templateId=<exact> accepts a strict object containing elementId and definitions. Each entry requires name and type. Optional defaultSource is a string carrying the exact JSON source, matching the F21 GET representation. JSON null in place of the optional string is malformed. A string containing a syntactically valid but semantically unready value follows F08 draft rules. Unknown or repeated members, noncanonical UUID, absent/null definitions and malformed input are refused. An empty array applies only to an element with no definitions. Estimate size using the existing 8 MiB HTTP envelope limit.

The condition is exactly one strong F21 If-Match. Missing condition returns 428, malformed condition 400, stale condition 412. Missing template/UUID is 404. Structurally invalid edited definitions return 422 without input echoes. F20's HTTPS/origin/permit rules and F22's final writer CAS apply. The edit uses templates.EditElementDefinitions. Preserve accepted revisions, other elements and independent raw values. A successful update returns 200, application/json, the canonical F21 body and matching ETag.
