## Why

Сторонний клиент должен явно переходить между персональными переменными и собственным JSON для одного общего элемента. [Задача #180](https://github.com/SunnyDayDev/xkeen-ui-server/issues/180).

## What Changes

Предоставить чтение и условное переключение режима одного элемента по правилам F13/B05. Запрос отдельно подтверждает возврат в переменные и полный сброс.

## Capabilities

### New Capabilities

- `external-router-replacement` — условное чтение и изменение полной замены одного элемента.

## Impact

Существующий F20, прикладной переход F13, writer C04, описание HTTP и OpenAPI.
