## Why

G13/G14 устанавливают транспортную службу. Проверенный E08 применяет ревизии в явно включаемой изолированной среде. [G18.1 #143](https://github.com/SunnyDayDev/xkeen-ui-server/issues/143) связывает две части, чтобы [G18 #141](https://github.com/SunnyDayDev/xkeen-ui-server/issues/141) проверял установленную нормальную службу с подтверждённым профилем.

## What Changes

- Отдельная явно выбранная роль применения с агентом и локальным supervisor из закреплённого ARM64 выпуска.
- Приём первоначального аттестованного рабочего окружения Xray и ограничений ядра до активации. Контролируемый запуск и восстановление E05 остаются в штатном supervisor.
- Два процесса и их готовность проверяются раздельно. Транспортный контакт не означает применение.
- Первый поддерживаемый стенд использует выделенный Xray и текущий профиль E08. Обновление профиля применения и проверка физических роутеров — отдельные задачи.

## Capabilities

### Modified Capabilities

- `entware-installation` — штатная установка явно управляемого профиля с защищённой локальной ролью.
- `agent-server-enrollment` и `agent-enrollment-client` — атомарное погашение приглашения в заранее закреплённой области и проверка привязки до синхронизации.

E08 остаётся источником доказательства для отчёта.

## Impact

Один дополнительный маршрут проверенного установщика и служба init.d. Роутер и связанный origin задаются через штатную конфигурацию, выпуск из GitHub использует формат [G16 #137](https://github.com/SunnyDayDev/xkeen-ui-server/issues/137). Сквозной сценарий использует операторские возможности F09, F10 и F18.
