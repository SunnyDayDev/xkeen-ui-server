## Проверяемая инструкция

Один документ показывает команды с точным тегом, отдельные UID/GID агента и сервера, root-only источник приватных файлов, TLS, F02 и проверку после stop/start. Доверенные значения предоставляются владельцем заранее. Пример тега заменяем. Опубликованный выпуск является внешним входом для эксплуатации. Сценарий испытания получает конкретные локальные синтетические версии с теми же путями и проверками без релиза.

Независимый разработчик сверяет команды с интерфейсом установщика и запускает их на чистом ARM64 Entware через воспроизводимый lab runner. В отчёте отдельно отмечаются готовность TLS/SQLite/Enrolment и последующий G18 с нормальным публичным интерфейсом и приложением Xray.
