## Context

В основной ветке GitHub в .github/workflows обнаружен только ci.yml. Кандидат первоначального G16 содержал отдельный workflow и POSIX builder. При пересмотре владелец оставил локальный builder.

## Decisions

Собирать файлы из точного git archive HEAD со штатным scripts/build-agent.sh и закреплённым Go. Зафиксировать статическую компоновку, архитектуру, формат и хеши. Отдельный временный каталог, блокировка на версию и финальное переименование защищают готовый набор от обычных конкурентных вызовов. При отсутствии скачанных Go-модулей локальной машине может потребоваться доступ к источнику зависимостей. Настройки GitHub не нужны.

## Risks / Trade-offs

Контрольные суммы показывают целостность. Метаданные владельца и манифест хранятся локально. Доверенную публикацию, подписывание и выбор промышленной версии владелец решает отдельно.
