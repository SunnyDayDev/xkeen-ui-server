## Purpose

Создать независимый вариант общего шаблона из конкретной сохранённой версии.

## ADDED Requirements

### Requirement: A template copy preserves saved content in a distinct scope

Авторизованный владелец SHALL выбрать сохранённую версию и ввести новый ID для копии. Копия SHALL иметь версию 1 и сохранять порядок, разделы, scoped UUID, сырой JSON, переменные и выключения.

#### Scenario: A saved template is copied and edited

- **WHEN** владелец копирует видимую сохранённую версию и меняет новый шаблон
- **THEN** данные исходника и его существующие назначения не меняются
- **AND** одинаковый UUID относится к разным источникам по ID шаблона

#### Scenario: The source changes or a destination already exists

- **WHEN** исходная версия изменилась, веб-сессия истекла или введённый ID уже занят
- **THEN** операция отклоняется атомарно без перезаписи или частичной копии

#### Scenario: The copy receipt is lost

- **WHEN** успешная запись могла произойти, а браузер не получил подтверждение
- **THEN** оператор может перечитать список и найти точный ID, а запрос не повторяется автоматически
