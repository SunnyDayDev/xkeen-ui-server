## Why

Владелец должен начать новый вариант профиля на основе выбранного шаблона, сохранив уже работающие назначения. [Issue #118](https://github.com/SunnyDayDev/xkeen-ui-server/issues/118).

## What Changes

- Действие «Копировать шаблон» из сохранённого черновика.
- Явный новый ID и отдельная версия 1 без общих назначений с исходником.

## Capabilities

### New Capabilities

- `web-template-copy`: копирование выбранной сохранённой версии в независимый редактируемый шаблон.
