## Decisions

Открывать форму из редактора сохранённой версии с точным ID источника, версией и новым ID по правилам F06. Видимое действие «Создать копию» сохраняет снимок C02, включая все секции и их порядок, порядок элементов, исходные JSON и дефолты, сохранённые определения, выключения и scoped UUID. C02 допускает тот же UUID в разных шаблонах. Пара «новый шаблон + UUID» становится новым источником. Сохранение UUID не переписывает пользовательский JSON и не ломает действующие маркеры A07. Новый ID создаётся с версией 1 без переноса принятых снимков, назначений, личных переопределений, желаемых ревизий или истории исходного шаблона.

Проверять исходную версию и текущий доступ F03 внутри SQLite writer, вставлять только новый ID. Повтор не перезаписывает существующий шаблон. Сбой или stale source оставляет оба шаблона и исходные назначения без изменений. После утраты ответа разрешить перечитать список и открыть точный новый ID, сохранив явность следующего действия. Не переносить несохранённый браузерный буфер.

## Risks / Trade-offs

До явного переключения профиля устройства продолжают ссылаться на прежний шаблон. Копия может сохранять допустимый незавершённый черновик и требует собственной приёмки перед использованием.
