## Context

F21 сериализует редактируемый снимок, F07 предоставляет правила редактирования, C03/F06 дают транзакционный CAS.

## Decisions

PATCH принимает ровно один If-Match в формате возвращённого сильного тега (ограничение F19), точный шаблон по query и строгий JSON с существующим UUID. Сначала F20 и проверка реального Origin. Внешний транспорт отвечает 428 без предусловия, 400 за неверный конверт или синтаксис условия, 412 за несовпадение сильного тега, 413 за большой body, 415 за неверный тип и 422 за ошибку содержимого. Отсутствующий ресурс даёт 404. Ошибки не повторяют сырой JSON. Полный успешный ответ и SHA-256 вычисляются тем же путём, что GET.

Использовать общий прикладной сценарий F07. SQLite adapter связывает исходный снимок с условием и делает recheck внешней настройки и C03 CAS под общей блокировкой writer. Конкурирующая веб-правка, переключение доступа или отзыв токена должны дать доказуемый отказ до изменения строк.

## Risks / Trade-offs

Клиент, потерявший успешный ответ, перечитывает выбранный шаблон по GET. Применение этой задачи ожидает принятую работу F07 и F21.
