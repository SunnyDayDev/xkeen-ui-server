## Реализация

Узкая операция G05 работает с подтверждённой связью C06 в SQLite. Прикладная граница принимает точный непустой UTF-8 RouterID и возвращает безопасные ошибки. Индексированная таблица хранит только скрытые ID. Пустая таблица при миграции сохраняет видимость прежних записей. Скрытие неподтверждённого и неизвестного ID отвергается одинаково.

Видимая проекция выбирает подтверждённые записи с существующим `agent_contacts` и без признака скрытия. Она возвращает точные самостоятельные ID, сторонние чтения настроек, статуса и публикаций остаются независимыми. F11 сможет использовать согласованную проекцию в своём read snapshot.

D06 снимает признак после апсерта подтверждённого контакта и до commit в том же writer. Replay и устаревшие подтверждённые номера сохраняют курсор. Конфликтующий replay не снимает признак. Сбой удаления признака откатывает сам контакт. Сокеты и API остаются прежними. Миграция переносится на следующий свободный номер после принятия F10, остальные номера не меняются.
