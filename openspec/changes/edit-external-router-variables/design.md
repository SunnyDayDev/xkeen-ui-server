## Context

F12 выбирает принятый снимок шаблона, действующее назначение и существующий C04-черновик либо активные настройки для первого редактирования. F20 связывает внешнее разрешение с поколением политики. F22 использует один сильный ETag и сравнение версии в SQLite.

## Goals / Non-Goals

Предоставить точное чтение и условную запись персональных значений одного общего UUID при неизменном режиме переменных. Поддержать диагностику B01 на сохранённом черновике. Публикация, смена профиля и переход между режимами выходят за эту операцию.

## Decisions

- `GET` и `PATCH /api/v1/routers/variables?routerId=<exact>&elementId=<uuid>`. У каждого параметра ровно одно значение. Чтение возвращает точные координаты роутера, шаблона, секции и элемента, поколения строками, режим и определения с активными значениями либо диагностиками. В режиме своей замены значения не раскрываются, PATCH возвращает 409.
- F12 остаётся общим переходом. Вынести авторизационно-независимые снимок и выбор одного общего элемента в прикладную область, сохранив браузерный выбор и его сессию. Прежняя операция допускает неготовый черновик. Синтаксический отказ атомарен, несоответствующие B01 тип и необязательное значение отражаются в диагностике. Операция проверяет точный принятый источник и меняет только имена из запроса.
- PATCH требует один точный сильный `If-Match` из GET. Тег связывает детерминированное тело, роутер, элемент, принятый шаблон, действующее назначение и поколение C04. Пакет `{"values":[{"name":"timeout","source":"30"},{"name":"host"}]}` сохраняет точные байты либо явно освобождает наследование. Строка `"null"` передаёт буквальный исходник, JSON null в поле source отклоняется. Пустой пакет, дубликаты и неизвестные имена отклоняются.
- F20 проверяется в том же SQLite snapshot, что и protected read. На записи повторно проверяются permit, видимость и принятое поколение, действующее назначение и версия черновика одним writer transaction. Совпадающие координаты двух роутеров не делают теги взаимозаменяемыми. Неявный повтор записи не выполняется.
- HTTP 428 для отсутствующего предусловия, 400 для неверной формы, 412 для устаревшего основания, 409 для собственной замены или другого шаблона черновика, 422 для синтаксиса исходника. Состояния внешнего допуска по F20. Ошибки не возвращают исходник и секреты.

## Risks / Trade-offs

Тег закрывает три поколения независимо. Чтение одного элемента уменьшает ответ и не вводит каталог F17. Версионная запись не подтверждает применённую конфигурацию.
