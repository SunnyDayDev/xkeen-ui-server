## ADDED Requirements

### Requirement: Personal exclusion editor binds the selected shared source

Сервис SHALL связывать персональный список с видимым роутером, действующим профилем и стабильным UUID принятой записи. Владелец SHALL видеть эффективный результат при наследовании и при полной буквальной замене, а при отсутствии источника или смене назначения — безопасный отказ.

#### Scenario: Returning to variables differs from resetting all settings

- **WHEN** пользователь явно возвращается из полной замены к значениям
- **THEN** собственный текст удаляется, прежние персональные значения остаются; явный отдельный полный сброс удаляет и их, сохраняя общий источник

#### Scenario: Stale or hidden source

- **WHEN** после чтения изменилось назначение, версия принятого общего источника или персональный черновик либо роутер скрыт
- **THEN** запись не меняет данные, потеря видимости скрывает содержимое, а конфликт предлагает явное перечитывание
