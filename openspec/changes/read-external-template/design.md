## Context

F19 определил схему, F20 проверяет HTTPS и выдаёт свидетельство поколения. Персональный draft UI и служебные данные агента в этот канал не входят.

## Decisions

Сохранить один путь чтения полной записи C02 в SQLite и один общий способ проверки восстановленного снимка. Транзакция чтения проверяет режим и версию допуска F20 и затем читает шаблон. В callback сериализации явно преобразовать версии в десятичную строку, отсутствующий дефолт опустить, точный пользовательский исходник оставить строкой, пустые массивы выдать как []. Сильный ETag — SHA-256 выданных байтов внутри кавычек. В пределах операции тело не преобразуется.

## Risks / Trade-offs

Данные шаблона могут содержать чувствительные значения. На ошибках исключить ID, содержимое и прочие значения из сообщений, не писать body или заголовки в журнал.
