## Context

Владелец выбрал независимые настройки и локальные правила каждого профиля. При первом переходе из «Дом» в «Офис» настройки «Дом» не копируются. Возврат в «Дом» использует его сохранённые данные и порядок, пересчитанные относительно текущего принятого шаблона. G02 владеет этой семантикой и атомарной фиксацией.

## Decisions

1. Карточка F11 открывает отдельный веб-сценарий по точному RouterID. В списке используются точные ID из защищённого F05. Выбор требует согласованного G02 Read принятой цели. Черновик без принятой версии имеет состояние недоступной цели.
2. Браузер показывает активный профиль, точную цель и происхождение персональных настроек. Новые поля связываются с общим элементом по UUID и точному имени переменной. Проверка обязательности, буквального JSON, зависимостей и Xray принадлежит уже работающим сервисам. Коды ошибки и безопасные позиции ограничены выбранным роутером и профилем. Для устаревшей ссылки вне редактируемых значений экран предлагает выбрать другой профиль или вернуться к настройкам. Он сохраняет прежние данные.
3. Подготовка выполняется без изменения назначения, сохранённой цели и ревизий. Сводка сообщает о смене активного профиля, использовании независимых настроек и воздействии на желаемый каталог. Совпадающий набор файлов может сохранить желаемый номер, при этом назначение меняется только при успешном подтверждении. UI отделяет это от E08.
4. Веб-квитанция короткоживущая и подписанная. Она связывает доказательство G02, точный роутер, цель, значения и допуск текущей F03 сессии. Переход на другого роутера либо смена цели или ввода очищает подготовку. Проверка владельца, срока и видимости повторяется под тем же финальным writer, который меняет назначение.
5. Сырой введённый текст удерживается в текущей вкладке по точному роутеру, цели и координате поля. После истечения сессии требуется новое явное действие. После неизвестного ответа выполняется отдельное чтение текущего назначения. Отмена и возврат переносят фокус к вызывающему действию, где оно ещё доступно.
6. Pencil показывает вход в карточке, выбор и пустую цель, обязательные значения, восстановление сохранённых данных, просмотр, отдельное подтверждение, ошибку и устаревание, неизвестный результат, принятое назначение и узкий экран. Проверяемый путь завершает часть #124.

## Verification

По принятому G02 тестируется штатный HTTPS процесс с SQLite, F03, изолированным Xray и синтетическими A/B. Chromium подтверждает клавиатуру на 320 px, первую смену и возврат данных, отсутствие действий до подтверждения, изменение общего шаблона, отмену, потерю ответа и отзыв сессии.
