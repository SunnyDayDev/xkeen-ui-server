## Purpose

Владелец безопасно меняет общий профиль точного роутера через проверенный переход G02.

## ADDED Requirements

### Requirement: The console previews another accepted profile

Веб-консоль SHALL показывать активный профиль, результат выбора принятой цели, состояние её персональных настроек и поля требуемых значений. Действующее назначение SHALL сохраняться до отдельного успешного подтверждения.

#### Scenario: First visit to another profile

- **WHEN** владелец выбирает впервые используемый принятый профиль
- **THEN** форма показывает начальное состояние его собственных персональных данных без копирования данных активного профиля
- **AND** незаполненные обязательные значения препятствуют подготовке

#### Scenario: Returning to a previously used profile

- **WHEN** владелец выбирает ранее использованный профиль
- **THEN** форма показывает, что будут восстановлены его сохранённые настройки и порядок по текущему принятому шаблону

#### Scenario: A target cannot be prepared

- **WHEN** выбранный профиль не принят, несовместим, изменился или кандидат не проходит проверку
- **THEN** консоль показывает причину и доступное продолжение, сохраняя активное назначение

### Requirement: The console requires separate exact confirmation

Консоль SHALL требовать отдельного подтверждения действующего проверенного плана. Изменение цели или входа SHALL отзывать возможность подтвердить прежний план. Изменение состояния на сервере SHALL проверяться при фиксации.

#### Scenario: Confirmed transition and agent evidence

- **WHEN** подтверждён точный действующий план
- **THEN** консоль показывает новое принятое назначение и желаемую ревизию
- **AND** факт агентского применения определяется отдельно

#### Scenario: User cancels, loses session, or loses the result

- **WHEN** владелец отменяет план, теряет доступ во время подтверждения либо ответ не дошёл
- **THEN** интерфейс очищает использованную возможность подтверждения и не повторяет запись автоматически
- **AND** при неизвестном исходе доступно явное чтение текущего назначения без вывода об исходе конкретного запроса
