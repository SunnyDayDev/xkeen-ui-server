## ADDED Requirements

### Requirement: Ordered router selection preserves chosen content

Сборка порядка одного роутера SHALL соединять полный список UUID из актуального шаблона и локальных правил с результатом выбора содержимого по `configuration-content-inheritance`. Она SHALL проверять полный список, включая исключённые общие UUID, до формирования видимого результата. Успешный результат SHALL содержать независимый полный порядок с происхождением каждого UUID и видимую последовательность активных правил с тем же происхождением и уже выбранным JSON. Исключённое общее правило SHALL занимать место только в полном порядке; его содержимое SHALL NOT собираться для видимой последовательности.

Перестановка SHALL NOT менять JSON, режим наследования, персональные значения, исходный шаблон или локальные записи и SHALL NOT интерпретировать выбранное содержимое повторно. Ошибка выбора содержимого либо порядка SHALL возвращать ошибку без частичного упорядоченного результата. Успех SHALL NOT означать готовность полного файла Xray или публикацию ревизии.

#### Scenario: Inherited and local content follow ID order
- **WHEN** общий A наследует актуальный JSON шаблона, локальное L содержит буквальный JSON, а полный порядок равен L, A
- **THEN** видимый порядок равен L, A с происхождением и соответствующим уже выбранным JSON каждого правила
- **AND** содержимое A и L не меняется из-за перестановки

#### Scenario: Full replacement moves without reassembling
- **WHEN** общее A использует собственный JSON целиком, а его UUID перемещён после локального L
- **THEN** видимый порядок равен L, A и A сохраняет выбранную полную замену без подмешивания шаблонного JSON или повторной подстановки

#### Scenario: Excluded rule keeps only its full-order position
- **WHEN** полный порядок равен A, B, L, общее B исключено и его содержимое не проходит проверку активного элемента
- **THEN** полный порядок сохраняет A, B, L с происхождением, а видимый содержит только выбранные A, L
- **AND** ошибка содержимого B не блокирует успешный результат при корректных метаданных B

#### Scenario: Content failure prevents ordered result
- **WHEN** полный порядок корректен, но выбор активного правила возвращает ошибку содержимого или персональных значений
- **THEN** сборка возвращает эту безопасную ошибку без полного и видимого кандидатов

#### Scenario: Order failure prevents ordered result
- **WHEN** содержимое активных правил выбрано успешно, но полный список порядка пропускает локальный UUID либо содержит повтор исключённого общего UUID
- **THEN** сборка возвращает соответственно order_element_not_found либо duplicate_order_element без видимого или полного кандидата

#### Scenario: Result and source data are independent
- **WHEN** вызывающая сторона меняет JSON либо списки успешного упорядоченного результата
- **THEN** входные данные, выбранное содержимое другого результата и последующая сборка остаются неизменными
