# Приёмка G13

- Поведенческий Red первого теста получен до появления скрипта. После bootstrap ARM64 Entware принял точные тег и SHA-256, отказал для другого тега и неверной суммы.
- Поведенческий Red полной установки получен со stub-утилитой. После реализации установленный агент прошёл реальное TLS-подключение к серверу и сохранил рабочий ID в SQLite.
- Отказ при недоступном сервере убрал незавершённое активное поколение и не зарегистрировал init.d. Точный повтор завершился с сохранённым приглашением.
- Повреждённый CA до первой установки и изменённый PEM перед стартом воспроизведены с Red. После исправления отказ наступает до запуска и сохраняет состояние.
- Утраченную регистрацию init.d повторно опубликовали с той же квитанцией текущего процесса. Stop/start сохранил клиентский ID, ключ и Generation 1. Чужой живой процесс остался работать при проверке совпадающего PID и времени старта.
- Результат подтверждён независимым ревью. Проверка воспроизводится в `sh lab/check-entware-install.sh` с ARM64 Docker Entware и изолированной сетью контейнера.
