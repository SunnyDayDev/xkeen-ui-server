# C06.1 — проверка реализации

Дата проверки — 2026-11-24. Критерии — [issue #50](https://github.com/SunnyDayDev/xkeen-ui-server/issues/50), родительская задача — [issue #49](https://github.com/SunnyDayDev/xkeen-ui-server/issues/49).

| Критерий | Результат |
| --- | --- |
| Полные снимки и обязательные группы | Для двух корректных пустых снимков точно совпали пять базовых файлов. Отсутствие снимка, разные ID шаблона, неверная версия, недопустимый ID и повторная группа дают отдельную ошибку без каталога. |
| Семантика B12 | Проверены точные байты персонального значения, полной замены с буквальной ссылкой, локального элемента, исключения и неизвестной группы с большим числом. Присутствие пустого stats сохранено, отсутствующий fakedns не добавлен. Совпадающие отключения учитываются один раз, персональный дубль отклоняется. Неподдерживаемое отключение возвращает исходную безопасную позицию. |
| Полное основание порядка | Проверены наследование, отсутствие порядка с локальным правилом, явно пустое основание, несовместимая версия и список, перестройка старого порядка. Позиции новых и выключенных или исключённых UUID остаются в полном результате. Исключение удалённого источника даёт ошибку B12. |
| Независимость и фактические проверки | Изменение файлов, списка и основания после возврата не меняет исходные данные или повторный результат. Независимый рецензент проверил код и повторил целевые тесты. |

## Red и Green

- Контекст и отображение групп. Тесты отсутствовали на C05. После добавления сценариев первый компиляционный Red показал отсутствие `PrepareRouterCandidate` и типа результата. Минимальное преобразование снимков в B12 дало Green для контекста, нормализации, точных файлов и отключений.
- Основание порядка. После добавления сценариев Red показал принятие неподтверждённого пустого порядка и отказ на ранее удалённом UUID до пересчёта. После проверки основания и вызова B08 по полной последовательности тесты прошли. Текущие исключения и отключения применяет B12 после пересчёта. Устаревший источник отклоняется с исходной позицией.
- После рефакторинга прошли целевые тесты подготовки, порядка и каталога. [Границы операции](../../../../docs/configuration-model.md#реализованный-шаг-c061).

## Команды

- Go 1.27.1 на Darwin ARM64. `go test ./internal/application/publication ./internal/configuration -count=1`, `go test ./... -count=1`, `go test -race ./... -count=1`, `go vet ./...`, `openspec validate prepare-router-publication-candidate --strict` прошли.
- Сервер и тестовый бинарник собраны для Linux ARM64 с `CGO_ENABLED=0`. `file` подтвердил для обоих ELF AArch64 со статической линковкой.
- Тестовый бинарник запущен в `xkeen-router-lab:dev` на Linux ARM64 с read-only root, отключённой сетью, непривилегированным процессом и одним read-only монтированием бинарника. Целевые тесты прошли. Проверялся Go-кандидат; точная проверка внешним Xray, фиксация ревизии и физические роутеры относятся к другим этапам.
