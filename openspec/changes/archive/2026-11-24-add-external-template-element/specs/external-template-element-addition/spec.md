## Purpose

Внешний HTTPS-клиент добавляет один элемент в точный сохранённый черновик.

## ADDED Requirements

### Requirement: An authorized client conditionally adds a stable element

Внешний клиент SHALL передать точные ID шаблона и секции, новый канонический UUIDv4, текст JSON и ETag прочитанного черновика. Сервер SHALL сохранить исходный текст, объявить обнаруженные переменные и атомарно вернуть обновлённое представление с новым ETag.

#### Scenario: An empty or populated template receives one element

- **WHEN** актуальный допуск и ETag разрешают запись нового UUID в поддерживаемую секцию
- **THEN** новый элемент появляется в конце этой секции либо открывает отсутствующую секцию
- **AND** существующие позиции, содержимое и конфигурации роутеров сохраняются

#### Scenario: The exact UUID is already in another section

- **WHEN** целевой UUID уже принадлежит любому элементу этого шаблона либо секция занята единственным допустимым элементом
- **THEN** возвращается конфликт и версия черновика сохраняется

#### Scenario: The draft or authorization changes before the writer

- **WHEN** допустимый ETag устарел либо допуск внешнего запроса больше не действует
- **THEN** сервер отклоняет запись без частичного изменения шаблона
