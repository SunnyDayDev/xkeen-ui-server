# C04. Сохранение настроек одного роутера

## Why

Вычисления B05, B06 и B08 получают состояние из памяти. [C04 / issue #38](https://github.com/SunnyDayDev/xkeen-ui-server/issues/38) сохраняет это состояние на центральном сервере, чтобы восстановить черновик после перезапуска и использовать его в дальнейшей публикации.

## What Changes

- Ввести внутренний контракт записи и чтения полного черновика одного роутера по стабильному ID.
- Сохранять профиль, выбранный шаблон, персональные значения, режимы, локальные элементы, исключения по секциям, полный персональный порядок и признаки отключения правил и входов.
- Добавить миграцию SQLite и проверить повторное открытие того же файла, различение отсутствия и пустого порядка и целостность при ошибке записи.

## Capabilities

### New Capabilities

- `configuration-router-storage` — устойчивое хранение черновика роутера и восстановление его точного состояния.

## Impact

Прикладной слой централизует контракт снимка. Адаптер SQLite из [C01 / issue #36](https://github.com/SunnyDayDev/xkeen-ui-server/issues/36) хранит его без чтения таблиц C02. Публикация и согласование изменений шаблона относятся к C05–C07, управление роутером через внешний API и интерфейс — к отдельным задачам.
