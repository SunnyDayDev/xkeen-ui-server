# Приёмка C04

[Issue #38](https://github.com/SunnyDayDev/xkeen-ui-server/issues/38). Проверены внутренние операции сохранения и чтения полного черновика роутера, целостность при ошибках, сохранность после повторного открытия и совместимость со схемой C02.

## Red и Green

| Сценарий | Red | Green |
| --- | --- | --- |
| Прикладной контракт чтения, записи и проверки структуры | До добавления пакета целевые тесты не собирались из-за отсутствующего интерфейса и реализации. | Точное чтение по ID, различение неизвестного ID, независимость роутеров, безопасные ошибки структуры и сохранение неготового черновика. |
| Миграция | На базе версии C01 целевой тест получил `sql: no rows in result set` при поиске таблицы настроек. | Миграция создаёт таблицу. После интеграции C02 проверены переход с v2 на v3 и сохранность записи в `templates`. |
| Адаптер SQLite | До добавления адаптера тесты не собирались из-за отсутствующего `NewRouterSettings`. | Снимки переживают закрытие и повторное открытие, сохраняют байты, режим, секции, независимые исключения и отключения, полный порядок и отличие nil от пустого списка. Ошибка записи сохраняет старый снимок и соседнюю запись, повторная запись заменяет снимок целиком. |
| Повреждённая оболочка снимка | Регрессионный тест воспроизвёл успешное чтение с отсутствующим полем порядка и с регистровыми дублями в снимке и группе. | Точные служебные поля проверяются до декодирования. Во всех трёх случаях возвращается ошибка повреждённой строки. |

## Выполненные проверки

- `go test ./internal/application/routersettings ./internal/storage/sqlite -count=1`
- `go test ./... -count=1`, `go test -race ./... -count=1`, `go vet ./...`
- `CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath ./cmd/xkeen-ui-server` и та же сборка с `GOARCH=amd64`, с выводом во временный каталог. `file` подтвердил два статических ELF нужных архитектур.
- Строгая валидация change и основной спецификации OpenSpec. Локальные ссылки и `git diff --check`.

Целевые тесты SQLite также запущены в отдельном Entware ARM64-контейнере без сети и рабочих томов. Выполнены миграция, закрытие и повторное открытие, ошибки повреждённой записи, отказ и повтор записи. Все сценарии прошли. [Стенд](../../../../lab/README.md).

```sh
probe_dir=$(mktemp -d)
trap 'rm -rf "$probe_dir"' EXIT
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go test -c \
  -o "$probe_dir/router-settings.test" ./internal/storage/sqlite
docker run --rm --platform linux/arm64 --network none --read-only \
  --tmpfs /tmp:rw,nosuid,nodev,noexec --cap-drop ALL \
  --security-opt no-new-privileges \
  --mount "type=bind,src=$probe_dir/router-settings.test,dst=/router-settings.test,readonly" \
  --entrypoint /router-settings.test xkeen-router-lab:dev \
  -test.run '^TestRouterSettings' -test.v
```

Проверено хранение черновика. Публикация, обработка правок нескольких устройств, интерфейс управления, физические накопители и узлы остаются отдельными задачами.
