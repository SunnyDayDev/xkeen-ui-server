# Приёмка проекта D02

[Issue #60](https://github.com/SunnyDayDev/xkeen-ui-server/issues/60). Проверены 5 требований и 13 сценариев жизненного цикла ключа.

| Критерий | Что сверено |
| --- | --- |
| Первое подключение и область доступа | Подтверждённое первое назначение и проверенный желаемый каталог C06 предшествуют административному выпуску. Приглашение ограничено сроком, целью и техническим ID. Рабочий ключ даёт полномочия только своего роутера. |
| Конкуренция и потеря ответа | Атомарное погашение допускает связать один кандидат. Повтор с тем же кандидатом подтверждает действующую привязку в пределах срока. Другой кандидат и повтор после замены или отзыва получают безопасный отказ. |
| Переустановка, замена, отзыв | Сохранённый ключ продолжает ту же регистрацию. Потеря ключа требует авторизованного восстановления. Замена сохраняет идентичность, отзыв прекращает полномочия. Удаление строки влияет на видимость по G04/G05. |
| Независимость каналов и хранение | Настройки внешнего API сами не предоставляют право выпуска. Сервер хранит проверочные значения, агент хранит нужный секрет локально. TLS и диагностика согласованы с D01. |
| Устойчивый порядок отчётов | Независимое ревью уточнило сценарий потери локальной очереди при действующем ключе. Перед следующим отчётом агент читает серверную границу в D06. Потерянное локальное состояние само не подтверждает применение. |

Сверены [контракт канала D01](../../../specs/agent-revision-synchronization/spec.md), [публикация первого назначения C06](../../../../docs/configuration-model.md#реализованный-шаг-c064) и архивация дельты. Обработчики, хранение ключей и их срок, проверка TLS в лаборатории, установщик и физические устройства относятся к последующим задачам.
