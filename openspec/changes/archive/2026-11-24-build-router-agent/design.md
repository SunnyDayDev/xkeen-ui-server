## Context

A02 подтвердил запуск статического Linux ARM64 ELF в Entware aarch64. D04 запускает агент в foreground, а E02–E08 используют отдельный локальный supervisor. Репозиторий закрепляет Go 1.27.1.

## Decisions

1. Сборочный скрипт вызывается из любого рабочего каталога, проверяет версию из go.mod и фиксирует Linux ARM64 v8.0 без cgo. Обе команды собираются с trimpath из того же снимка. Манифест SHA-256 завершается после успешной сборки обоих файлов.
2. Стенд использует именно выданные файлы. Непривилегированный агент с синтетическим приглашением проходит штатный TLS/SQLite тест, после перезапуска сохраняет имя устройства. Для supervisor проверяется узкая диагностическая команда в том же Entware.
3. Автоустановка, защищённый профиль рабочего Xray, проверка ядра и безопасное обновление относятся к G12–G15. Артефакты и контрольные суммы остаются локальными. Поставка не создаёт выпуск и не выбирает лицензию.

## Risks / Trade-offs

ARM64 v8.0 соответствует исследованной архитектуре. Запуск в контейнере подтверждает совместимость наблюдаемой среды. Поддержка физических накопителей и дополнительных платформ будет отдельной проверкой.
