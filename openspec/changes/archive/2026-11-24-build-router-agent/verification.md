# Проверка сборки ARM64 G11

[Issue #106](https://github.com/SunnyDayDev/xkeen-ui-server/issues/106) использует наблюдавшийся профиль A02. Первоначальный тест получил Red из-за отсутствовавшего сборочного скрипта. После реализации два бинарника собраны проверенным Go 1.27.1. `file` определил статические Linux ELF AArch64. `go version -m` подтвердил `GOARM64=v8.0` и `CGO_ENABLED=0`. Повторная сборка в другом каталоге дала идентичную ведомость SHA-256.

Для прогона использованы именно файлы из результата скрипта. Под непривилегированным UID в изолированном Entware aarch64-k3.10 агент выполнил TLS-привязку через SQLite, повторный запуск с сохранённой идентичностью и управляемую остановку. Отдельный бинарник supervisor успешно прочитал локальный идентификатор запуска процесса внутри контейнера через `--working-process 1`.

```sh
sh scripts/build-agent.sh .build/agent-arm64
sh lab/check-agent-artifact.sh
```

Go и Docker нужны на сборочном хосте. Сетевой доступ контейнеров отключён. Испытание проверяет набор артефактов и штатный запуск. Установка, производственные профили и физические устройства входят в другие этапы. Бинарники собираются локально.

Независимое ревью подтвердило настройки cross-build, публикацию манифеста после файлов и запуск именно сформированной пары. Скрипт также проверен из отдельного рабочего каталога с пробелом в пути результата.
