# Проверка F07

- Через MCP Pencil перенесены только восемь состояний экрана 23. Навигация взята из совмещённых состояний F06/F20. Независимо проверены широкий, узкий экран, первое сохранение и конфликт. Форма на 390 px сверена в Chrome; горизонтального переполнения нет.
- Red: тесты чистой правки и SQLite выявили отсутствие операций. Настоящий HTTPS вернул 404 на запроектированном маршруте. В Chrome ожидание штатной ссылки элемента завершилось отказом до реализации. Отдельная браузерная проба показала зависшую форму после смены полномочия во время сохранения.
- Green: существующий элемент сохраняет UUID, порядок и отключение. Точная правка проверена на смешанных CRLF/LF, многоязычном JSON, точном числе, вставке и отмене изменения. A08 обнаруживает ссылки только в изменяемом элементе; сохранённое соседнее определение не переобъявляется. Конкурентный SQLite writer пропускает ровно одну версию. Отзыв блокирует чтение и запись; некорректный JSON получает позицию без записи.
- Chrome через штатный Go HTTPS и SQLite проверил первое сохранение, точную загрузку, синтаксический отказ, конфликт с ручным показом актуальной версии, смену полномочия при ожидающем ответе и повторный вход без автоматической записи.
- Лабораторный сквозной Go тест через HTTPS прошёл в отдельном Entware aarch64-k3.10 под LinuxKit 7.0.14 с лимитом 256 МиБ. Пик контейнера 185520128 байт, OOM-убийств нет.
- Дополнительные Red/Green проверили ранний отказ POST без сессии и отмену выбора другого UUID при смене полномочия. Запоздалый ответ отклоняется, прежний точный буфер снова доступен.
- Полные Go test, race и vet, Linux AMD64/ARM64 без cgo, воспроизводимый Vite и OpenSpec strict прошли.
