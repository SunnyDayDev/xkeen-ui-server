## ADDED Requirements

### Requirement: Isolated execution of the pinned validator

Сервис SHALL выполнять проверку точных файлов только в ограниченной одноразовой среде выбранного профиля.

#### Scenario: File initialization during the test
- **WHEN** Xray инициализирует предусмотренный профилем файловый журнал
- **THEN** запись возможна только в отведённом временном пространстве попытки, кандидат сохраняет исходные байты
- **AND** процессу недоступны настройки сервера и роутера, постоянные журналы, сокеты управления и внешняя сеть

#### Scenario: Isolation or resources unavailable
- **WHEN** ограничения нельзя установить либо проверка превысила срок или ресурсный лимит
- **THEN** результат означает недоступность проверки, выполнение прекращается, временные данные освобождаются, публикация заблокирована

### Requirement: Full catalog disclosure requires an explicitly trusted validator

Сервис SHALL передавать полный каталог внешнему исполнителю только при явной настройке его адреса и доверия обеих сторон через защищённый канал.

#### Scenario: Remote validation requested
- **WHEN** настроен доверенный внешний исполнитель и проверены удостоверения сервера и исполнителя
- **THEN** только этот исполнитель получает исходные имена и байты всех файлов, включая персональные секреты, и проводит изолированную проверку

#### Scenario: Remote transmission is not authorized
- **WHEN** внешний режим не настроен, проверка удостоверения не прошла или получатель предлагает перенаправление
- **THEN** каталог не передаётся неподтверждённому получателю, другой адрес автоматически не выбирается
- **AND** отсутствие доступного выбранного исполнителя блокирует публикацию и позволяет продолжать работу с черновиками

### Requirement: Each result identifies one exact validation attempt

Сервис SHALL принимать ответ выбранного исполнителя только при подтверждённом соответствии текущей попытке, её профилю и точному набору именованных байтов.

#### Scenario: Recognized outcomes for the current request
- **WHEN** закреплённый Xray завершил проверку полного переданного каталога и исполнитель подтвердил его принятие или отказ
- **THEN** вызывающий получает соответствующий результат для этого каталога без конфигурации, вывода Xray и временных путей

#### Scenario: Invalid or stale response
- **WHEN** ответ относится к другой попытке, версии или именованным байтам либо его формат или происхождение нельзя подтвердить
- **THEN** проверка недоступна, результат нельзя использовать для принятия ревизии
