# Проверка E05

Linux ARM64 LinuxKit, Entware aarch64-k3.10, Xray 26.3.27, синтетические данные и контейнер без внешней сети. [Issue #87](https://github.com/SunnyDayDev/xkeen-ui-server/issues/87).

| Рубеж E01 | Подтверждение |
| --- | --- |
| 1. До устойчивого намерения | Запуск повторно проверяет прежний процесс и каталог, оставляет прежнюю квитанцию. |
| 2. Устойчивое намерение, эффект не доказан | Planned не служит доказательством отсутствия эффекта. Возврат к прежней базе проходит полную проверку. |
| 3. Остановка, частичная запись | Пропавший необязательный файл возвращается, рабочая генерация доказана. Отсутствие центрального CA оставляет локальный API недоступным после успешного локального восстановления. |
| 4. Новый диск без доказанного запуска | Полный целевой набор без аттестации возвращается к прежней генерации и её трафику. |
| 5. Неоднозначный горячий эффект | Синтетическая запись незавершённого намерения и несовпадающей квитанции проходит общий E04; реальный горячий API проверяет E07. |
| 6. Видимый commit без подтверждённого sync | Инъекция отказа sync после rename оставляет запись видимой. До повторного sync launcher не вызывается. После sync требуются обычные свежие проверки. |
| 7. Устойчивый commit без отчёта | После SIGKILL supervisor исторический ID и реальный Xray сохраняются; сервер не получает искусственный applied. |
| 8. Отказ и конфликт | Чужой синтетический файл не перезаписывается, повторный старт отвергается, защищённый журнал и прежняя история сохраняются. |

Red целевых тестов завершился ошибкой компиляции по отсутствующей операции. Green подтвердил восемь рубежей, отмену и повтор восстановления. Отдельная инъекция подтверждает границу между видимым commit и долговечностью. Первый полный прогон выявил ожидание старого E03 fixture о постоянном отказе для восстанавливаемого намерения. Исправленная проверка доказывает запуск только с точной прежней генерацией. Полный повтор стенда прошёл.

В Entware пройдены локальная матрица и четыре сквозных сценария E03/E04/E05. Проверены конкурирующий запуск, SIGKILL supervisor, повтор, сохранность локального трафика и отсутствие отчёта applied. Прерывания отдельных точек представлены защищёнными снимками, состояния процесса и файлов проверяются настоящим launcher. Отключение питания и физический роутер не участвовали.

```sh
XKEEN_LAB_APPLICATION=1 sh lab/check-agent-preparation.sh
go test ./...
go test -race ./...
go vet ./...
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go vet ./...
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build ./...
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build ./...
```

Независимое ревью и строгий OpenSpec прошли.
