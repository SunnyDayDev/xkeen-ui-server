# Проверка внешнего подтверждения общей публикации

- Red в потребительском тесте штатного HTTPS-процесса с SQLite. Защищённый маршрут подтверждения возвращал 404.
- Green с изолированной проверкой Xray. Действующим назначениям, включая офлайн, одновременно записаны новые желаемые номера. Устаревший источник, чужой шаблон и квитанция веб-сессии отвергнуты. Повторный GET после подтверждения возвращает сохранённые номера без вывода о состоянии Xray.
- Восемь повторов целевых проверок SQLite и прикладного сценария с детектором гонок. Поздняя смена политики или истечение квитанции оставляют данные и уведомления без изменений. Повтор неизменившегося плана без участников сохраняет результат.
- Полный набор Go, go vet и браузерные сценарии штатного HTTPS-сервера прошли. На ARM64 Entware восемь проверок прошли при ограничении 256 МиБ, пик потребления 184786944 байта, oom_kill 0.
- Независимое ревью завершено. CI и состояние issue проверяются отдельно по точному PR.
