## Purpose

Внешний клиент атомарно подтверждает один проверенный план общей публикации.

## ADDED Requirements

### Requirement: External confirmation publishes exactly the authorized verified plan

Сервер SHALL повторно проверить точный план, допуск и срок квитанции и атомарно зафиксировать общий снимок и желаемые ревизии всех изменившихся действующих назначений. Доступность роутера SHALL быть независима от участия и подтверждения агентского применения.

#### Scenario: A valid plan includes an offline router

- **WHEN** внешний клиент явно подтверждает проверенный актуальный план
- **THEN** сервер сохраняет все изменения и возвращает точные желаемые ревизии, включая участника без связи

#### Scenario: The verified candidate or permit changes

- **WHEN** хотя бы одна версия, состав, байты, результат проверки, срок или внешний допуск перестали соответствовать плану
- **THEN** сервер отклоняет подтверждение без частичной записи и сигнала новой ревизии

#### Scenario: An exact candidate changes no router files

- **WHEN** проверенный план принятия общего снимка не меняет ни одного действующего каталога
- **THEN** желаемые ревизии сохраняют номера и ответ не заявляет об агентском применении

#### Scenario: An uncertain confirmation is followed by a read

- **WHEN** внешний клиент потерял ответ подтверждения и перечитывает текущую публикацию
- **THEN** сервер возвращает только сохранённый общий снимок и желаемые номера этой области без оценки исхода конкретного вызова и без записи
