## ADDED Requirements

### Requirement: Substitution from prepared element values

Сервис SHALL предоставлять отдельную операцию подстановки, принимающую ID элемента, сырой JSON шаблона и подготовленный набор значений по именам только этого элемента. Подготовленный набор SHALL содержать уже выбранные значения: строки, числа, boolean, объекты или массивы, без определений и дефолтов. Операция SHALL использовать JSON-тип каждого переданного значения без автоматического преобразования и SHALL NOT самостоятельно выбирать дефолт или искать значения в других элементах.

Для шаблона с корректными целыми ссылками `${name}` и постоянными значениями операция SHALL подставлять значения в корне, полях объектов и элементах массивов, сохраняя структуру, неизвестные поля и порядок массивов. Имя SHALL сравниваться целиком, с учётом регистра, без обрезки и нормализации; точка SHALL оставаться частью имени. Числа как шаблона, так и подготовленных значений SHALL сохранять математическое значение без потери точности; форматирование и порядок ключей объектов не являются контрактом.

Подготовка набора и проверка полной конфигурации остаются отдельными операциями. Успех этого шага SHALL NOT означать выполнение всех требований полной сборки: проверки определений, заполненности, null и полного синтаксиса сохраняют силу на границе полной сборки. Гарантии этого шага для подготовленных входов не вводят разрешение на запрещённые полной сборкой данные.

#### Scenario: Prepared values retain all five types

- **WHEN** шаблон и подготовленные значения равны

```json
{
  "template": {
    "host": "${host}",
    "port": "${port}",
    "enabled": "${enabled}",
    "options": "${options}",
    "targets": "${targets}"
  },
  "values": {
    "host": "edge.example.com",
    "port": 443,
    "enabled": false,
    "options": {"network": "tcp"},
    "targets": ["example.net"]
  }
}
```

- **THEN** результат равен

```json
{
  "host": "edge.example.com",
  "port": 443,
  "enabled": false,
  "options": {"network": "tcp"},
  "targets": ["example.net"]
}
```

#### Scenario: Root substitution preserves the supplied type

- **WHEN** корневой шаблон `"${value}"` получает поочерёдно `"443"`, `0`, `false`, `{}` и `[]`
- **THEN** результат в каждом случае равен переданному значению с его JSON-типом
- **AND** строка `"443"` остаётся строкой, а `0`, `false` и пустые контейнеры не исчезают

#### Scenario: Nested references and unknown fields are preserved

- **WHEN** шаблон равен `{"custom":{"items":[{"port":"${port}"},"fixed","${port}"]},"extension":true}` и `port` равен `443`
- **THEN** результат равен `{"custom":{"items":[{"port":443},"fixed",443]},"extension":true}`
- **AND** неизвестные поля, постоянные значения и порядок массива сохраняются

#### Scenario: Exact names and element isolation

- **WHEN** два отдельных вызова используют шаблон `{"address":"${server.address}"}` и собственные наборы со значениями `one.example.com` и `two.example.com` для имени `server.address`
- **THEN** каждый результат содержит значение своего набора
- **AND** наличие только имени `server` с объектом `{"address":"one.example.com"}` не разрешает ссылку `server.address`
- **AND** наличие только имени `Server.Address` также не разрешает ссылку `server.address`

#### Scenario: Numbers in templates and values remain exact

- **WHEN** шаблон равен `{"constant":9007199254740993,"selected":"${n}"}` и `n` равен `9007199254740993`
- **THEN** оба числа в результате равны `9007199254740993`, без округления
- **AND** подстановка `0.12345678901234567890123456789` и `1e400` также сохраняет математическое значение

#### Scenario: Constant template needs no values

- **WHEN** корректный шаблон без ссылок, например `{"custom":[0,false,"fixed",{},[]]}`, получает пустой набор
- **THEN** результат семантически равен шаблону

### Requirement: Prepared substitution rejects invalid JSON inputs

Операция подстановки SHALL разбирать шаблон и каждое подготовленное значение как ровно одно JSON-значение. Неправильный или незавершённый JSON и лишний текст после значения SHALL приводить к `invalid_json`; повторяющиеся ключи объекта на любой глубине SHALL приводить к `duplicate_json_key`. Сравнение ключей SHALL выполняться после JSON-декодирования строк. Проверка SHALL охватывать и переданные значения, которые не используются в шаблоне. Одинаковые ключи в разных объектах SHALL быть допустимы.

#### Scenario: Invalid template has a safe position

- **WHEN** шаблон содержит незавершённый объект, два корневых значения или текст после завершённого значения
- **THEN** операция возвращает `invalid_json`, ID элемента, источник `template` и позицию ошибки без сырого JSON
- **AND** результат отсутствует

#### Scenario: Invalid supplied value is identified

- **WHEN** подготовленное значение `options` содержит неправильный JSON или два корневых значения, независимо от наличия ссылки на `options`
- **THEN** операция возвращает `invalid_json`, ID элемента, источник `value`, имя `options` и позицию ошибки
- **AND** результат отсутствует

#### Scenario: Duplicate keys are detected after decoding

- **WHEN** шаблон или подготовленное значение содержит `{"nested":{"a":1,"\u0061":2}}`
- **THEN** операция возвращает `duplicate_json_key` по пути `/nested/a`, с ID элемента и соответствующим источником
- **AND** для подготовленного значения указывается его имя
- **AND** результат отсутствует

#### Scenario: Keys in separate objects do not collide

- **WHEN** шаблон равен `{"first":{"a":1},"second":{"a":2}}` и набор пуст
- **THEN** операция успешно сохраняет оба объекта

### Requirement: Prepared substitution returns an atomic result and located errors

Если корректная целая ссылка отсутствует в подготовленном наборе, операция SHALL возвращать `unknown_variable`, ID элемента, источник `template`, точное имя и путь к ссылке. Путь SHALL использовать JSON Pointer: `~` экранируется как `~0`, `/` как `~1`, корень обозначается пустой строкой, элементы массива — индексами от нуля.

Операция SHALL возвращать либо новый JSON-результат без ошибок, либо как минимум одну конкретную диагностику и отсутствие результата. Шаблон и набор значений SHALL оставаться неизменными при успехе и ошибке; изменение возвращённого результата после успеха SHALL NOT менять входы. Диагностика SHALL NOT включать исходные значения или сырой JSON. Порядок и полнота накопления независимых ошибок не являются контрактом.

#### Scenario: Unknown variable identifies a nested reference

- **WHEN** элемент `outbound-demo` содержит `{"settings":{"address":"${missing}"}}` и набор не содержит `missing`
- **THEN** возвращается `unknown_variable`, ID `outbound-demo`, источник `template`, имя `missing` и путь `/settings/address`
- **AND** результат отсутствует

#### Scenario: Root and escaped paths locate unknown references

- **WHEN** ссылка `${missing}` находится в корне JSON либо в шаблоне `{"a/b~c":["${missing}"]}`
- **THEN** ошибка имеет соответственно пустой путь либо `/a~1b~0c/0`

#### Scenario: Error preserves all inputs and does not disclose data

- **WHEN** шаблон содержит известную и неизвестную целые ссылки, а подготовленный набор содержит строковое значение `demo-private-value`
- **THEN** операция возвращает ошибку неизвестной ссылки и не возвращает частичный JSON
- **AND** шаблон и все подготовленные значения остаются прежними
- **AND** диагностика не содержит `demo-private-value` или текст шаблона

#### Scenario: Successful result does not share writable input data

- **WHEN** успешная подстановка завершена и потребитель изменяет полученный результат
- **THEN** исходный шаблон и подготовленные значения остаются прежними
