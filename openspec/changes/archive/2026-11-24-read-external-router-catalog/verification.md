# Проверка внешнего каталога

Штатный процесс HTTPS на SQLite сначала вернул 404 после разрешения F20. Green возвращает пять точных сохранённых файлов с номером желаемой ревизии. Собранные персональные файлы содержат точное значение 9007199254740993 и отдельное доказательство сборки. Неудачная сборка возвращает 422 без частичных файлов. Вторая проверка внешнего допуска срабатывает после чтения, в том числе при ротации. Мутаций ревизий и статуса применения нет. Проверены неавторизованный, открытый и защищённый режимы, скрытый роутер и строгий query. Целевой race SQLite повторён восемь раз; браузерный канал сохранил прежние проверки приложения. Независимое ревью завершено.
