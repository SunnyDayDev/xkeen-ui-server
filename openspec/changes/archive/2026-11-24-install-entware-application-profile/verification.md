# Приёмка G18.1

- ARM64 Entware через синтетическое HTTPS-зеркало. Red показал отсутствие установленной роли. Green запустил проверенные supervisor и агент через зарегистрированную службу. Доказан собственный no_new_privs без глобального флага контейнера.
- SIGKILL установки после готовности supervisor и до готовности агента. Подложная квитанция с живым чужим PID и правильным start tick не разрешила продолжение или сигнал. Действительный точный повтор сохранил прежний supervisor и защищённый журнал.
- Контакт сам по себе не сообщил применение. Внутренний синтетический вызов публикации C06 проверил точный каталог, настоящий Xray выполнил рестарт, а доказательство E08 продвинуло принятый отчёт. Следующий init.d старт использовал журнал. Полная операторская приёмка F09/F10/F18 остаётся в G18.
- TLS/SQLite Red scoped enroll показал прежний отказ для неизвестного поля. Green проверил роль с неверным ожидаемым ID на настоящем агенте, отсутствие погашения, ключа и контакта, затем успешное погашение и точный повтор ожидаемого RouterID. Старые D03 запросы остались совместимыми.
- Независимый повтор Go и `XKEEN_LAB_INSTALLED=1 sh lab/check-agent-preparation.sh` прошёл. В тесте LinuxKit ARM64, Entware и Xray 26.3.27. Физических устройств и публикации релиза не было.
