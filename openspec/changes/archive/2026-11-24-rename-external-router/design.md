## Decisions

Добавить отдельную метадату отображения с монотонной версией по точному RouterID. Старые устройства читают сохранённое F09 имя как начальное, пустое отображается точным ID. Имя не изменяет опубликованный конфиг, persistent F09/C07 basis, исходники Xray, сессии, ключ или desired/applied. Общий F11 и внешний список используют display name после изменения. Изменения публикации сохраняют метадату, поскольку это независимая таблица. Не добавлять форму в браузер в рамках API.

GET требует подтверждённый роутер и действующий F20, возвращает routerId, name и сильный ETag назначения и метадаты. PATCH принимает один точный If-Match, объект с присутствующим name и ограничения UTF-8/непустого ввода F09. Хранить допустимое имя точно, без нормализации, если это разрешено существующей проверкой. Writer проверяет допуск, точный роутер и версию вместе. Неизменившееся значение можно вернуть без повышения версии. Точный запрос имени по этой операции допускается для скрытого устройства. Другие операции сохраняют свои ограничения G05.

## Risks / Trade-offs

F20 действует по явной настройке владельца. Точные значения и цели проверяются на момент чтения или транзакции записи.
