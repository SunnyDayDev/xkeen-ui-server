## Why

Сервер и агент уже проверены в Docker и Entware ARM64. [Issue #115](https://github.com/SunnyDayDev/xkeen-ui-server/issues/115) задаёт контракт доставки и обслуживания файлов из GitHub после G10/G11. G13–G18 реализуют и проверят этот контракт.

## What Changes

- Описать доверенную загрузку установщика по точному commit и компонентов конкретного явно выбранного выпуска.
- Согласовать Entware init.d, роли, каталоги, права, собственную проверку готовности и сохранение действующей установки при отказе.
- Определить модель смены поколения, границы миграции SQLite и неразрушающее удаление.
