## Context

Перемещать общие и локальные правила явным действием, с клавиатурным эквивалентом. Вернуть порядок шаблона по B07 с сохранением позиций локальных правил. Полный порядок включает скрытые и отключённые элементы. Используются F14, B07, B08, C04.

## Decisions

Оперировать полным порядком и сохранённым основанием F14. B08 MoveRule применяет указанный UUID и позицию без пересортировки по источнику; B07/B08 ResetRuleOrder переставляет общие UUID по шаблону и сохраняет локальные числовые позиции. Не преобразовывать унаследованное nil в пустой список и обратно без явной операции. При изменении принятого общего снимка сначала вычислить актуальное основание через B08 либо потребовать безопасной сверки. C04 writer сверяет участки порядка, актуальность версии и сессию; сохранение другого режима не перемещает правила. Изменение отдельной позиции сохраняется одним явным перетаскиванием или нажатием «Выше» / «Ниже». Кнопки доступны с клавиатуры. Возврат требует отдельного подтверждения. При конфликте интерфейс предлагает перечитать полный порядок, действие повторяется вручную.

## HTTP и сохранение

F14 `GET /ui/v1/routers/rules?routerId=<exact>` остаётся источником полного списка. `PATCH` по этому же адресу принимает полную основу F14 и один из двух вариантов: `{"action":"move","ruleId":"<uuid>","position":0}` с итоговым индексом полного списка, либо `{"action":"reset"}` без координат. Оба проходят F03 Origin, сессию и CSRF. Приложение загружает использованный снимок, выполняет B08-переход и передаёт независимого кандидата в прежний `WriteOrder`. Writer ещё раз сравнивает поколение и принятый снимок. Ответ содержит новый полный список и основу, как после вставки F14. Некорректный индекс или UUID отклоняются. Пользовательский drop на своё место ничего не отправляет.

Кнопки сохраняют новую позицию сразу. По ответу фокус возвращается к той же строке по UUID; сообщение о сохранении объявляется функциями доступности браузера. Ошибка после команды удерживает ранее показанный порядок без предположений об эффекте, требует перечитать и повторить действие явно. Переключение сессии отменяет запрос и игнорирует запоздалый ответ.

## Risks / Trade-offs

Сетевой отказ и неполное доказательство не подтверждают изменение. Места ошибок и безопасные диагностические результаты сверяются с актуальными входами на штатном сервере.
