## Purpose

Изменять персональный порядок правил в авторизованной браузерной области центрального сервера.

## ADDED Requirements

### Requirement: The operator can reorder shared and local rules

Редактор SHALL поддерживать перестановку общих и локальных UUID и отдельный возврат общего порядка по B07. Изменение SHALL сохранять полный список, содержимое и локальные позиции при возврате.

#### Scenario: A local rule can move across a shared rule
- **WHEN** владелец явно меняет позицию существующего правила клавиатурой либо перетаскиванием
- **THEN** сохраняется новый полный порядок UUID, меняется только порядок

#### Scenario: Reset restores shared order around local positions
- **WHEN** владелец возвращает порядок шаблона при наличии локальных правил
- **THEN** общие UUID возвращаются к порядку шаблона, локальные остаются на своих числовых позициях

#### Scenario: Reset without local rules returns to inheritance
- **WHEN** владелец подтверждает возврат порядка, а локальных правил нет
- **THEN** настройки снова наследуют порядок шаблона, включая последующее изменение общего порядка

#### Scenario: Stale reorder preserves the stored draft
- **WHEN** версия принятого шаблона или поколение настроек меняется после чтения
- **THEN** перемещение или возврат отклоняется без новых данных, а оператор может явно перечитать и повторить действие
