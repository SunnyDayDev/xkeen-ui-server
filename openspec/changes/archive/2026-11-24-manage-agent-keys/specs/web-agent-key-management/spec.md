## Purpose

Владелец управляет доступом агента к прежнему роутеру без потери серверной истории.

## ADDED Requirements

### Requirement: Agent key replacement has its own explicit workflow

Владелец SHALL получить одноразовое приглашение для нового рабочего ключа существующего роутера через отдельное явное действие. Действующий ключ SHALL работать до успешного погашения приглашения либо отдельного отзыва.

#### Scenario: An operator transfers access to a reconfigured agent

- **WHEN** владелец передал действительное приглашение агенту для прежнего RouterID
- **THEN** новый ключ атомарно становится действующим, прежний прекращает действовать
- **AND** ID, настройки, желаемые ревизии и серверный курсор сохраняются

#### Scenario: A replacement response is unknown

- **WHEN** ответ потерян, просрочен либо относится к прежней сессии или области
- **THEN** интерфейс очищает секрет, позволяет прочесть безопасные метаданные и не повторяет выдачу автоматически

### Requirement: Revocation stops agent authorization and invalidates pending invitation

Владелец SHALL иметь отдельное подтверждаемое действие отзыва. Отзыв SHALL прекращать действие рабочего ключа и отменять ожидающее приглашение, сохраняя техническую идентичность и историю.

#### Scenario: The agent is offline during revocation

- **WHEN** владелец подтверждает отзыв недоступного агента
- **THEN** прежний ключ и ожидающее приглашение не позволяют возобновить связь
- **AND** интерфейс объясняет необходимость отдельной локальной настройки нового ключа

#### Scenario: An operator restores access after revocation

- **WHEN** владелец подтверждает восстановление подключения прежнего RouterID после отзыва
- **THEN** выдаётся новое одноразовое приглашение с текущей эпохой
- **AND** старые реквизиты остаются недействительными, а успешная регистрация сохраняет серверный курсор

#### Scenario: An operator reviews credential management events

- **WHEN** владелец или администратор смотрит диагностические события ротации и отзыва
- **THEN** события не содержат исходный секрет или его проверяемое представление
