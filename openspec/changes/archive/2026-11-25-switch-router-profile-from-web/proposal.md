## Why

Владелец меняет общий профиль конкретного роутера после проверки последствий. [G03 #236](https://github.com/SunnyDayDev/xkeen-ui-server/issues/236) использует политику [G01 #129](https://github.com/SunnyDayDev/xkeen-ui-server/issues/129) и атомарный сервис [G02 #130](https://github.com/SunnyDayDev/xkeen-ui-server/issues/130).

## What Changes

- В карточке роутера появляется выбор другого профиля и отдельная проверка кандидата.
- Владелец видит требуемые значения, происхождение целевых настроек и последствия до явного подтверждения.
- Обзор обновляет назначение после подтверждённого результата. При потере ответа интерфейс предлагает явное чтение текущего назначения.

## Capabilities

### New Capabilities

- `web-router-profile-switching`: выбор, проверка и отдельное подтверждение смены профиля в консоли владельца.

### Modified Capabilities

Нет.

## Impact

Карточка F11, API F03, G01/G02 и уже работающие шаги сборки и публикации. Внешний API относится к #178. Клавиатурный сценарий дополняет #124.
