# Проверка F05

- Pencil: проверены список C0mXcM, пустое состояние XoSG3, ошибка VBn5i, загрузка KLp26 и узкая компоновка esEtd. Независимая проверка макетов пройдена до разработки.
- Red: тесты SQLite и HTTP подтвердили отсутствие запроектированного порта и маршрута. Тест браузера после реального входа остановился на отсутствии перехода «Шаблоны». Отдельная регрессия воспроизвела выдачу испорченного ID с недопустимым UTF-8.
- Green: SQLite читает метаданные в одном снимке с проверкой сессии, сохраняет порядок и точный int64, отвергает недействующие сессии и испорченное значение, не читает содержимое черновиков. HTTP выдаёт пустой массив, действительный список и безопасные ошибки. Процессный тест читает шаблон, созданный через C02, и проверяет отказ после локального сброса.
- Браузер Chromium через реальный Go HTTPS и SQLite: загрузка, пустота, ошибка, ручной повтор, навигация и история, обновление прямого адреса, длинный ID, версия 9223372036854775807, HTTP 401 и возврат после повторного входа. На ширине 360 px нет горизонтальной прокрутки, длинный ID и версия видны. Встроенная Vite-сборка на Node 26.5.0 воспроизводится.
- Полные Go test и race с локальным ограничением параллелизма, Go vet, сборки Linux AMD64/ARM64 и git diff --check прошли. Первый параллельный локальный прогон с несколькими одновременными сборками упёрся в пятисекундный таймаут существующего TestProcessAgentTLSInvalidConfig. Отдельная проверка и полные повторные прогоны прошли.
- Матрица реального HTTPS выполнена через lab/check-web-administrator.sh в изолированном Entware aarch64-k3.10 под LinuxKit 7.0.14 с лимитом 256 МиБ. Пик 180809728 байт, oom_kill 0.
- Независимая проверка SQLite, HTTP, гонок и реального браузера выполнена. Статус обязательного CI можно проверить в PR с изменением.
