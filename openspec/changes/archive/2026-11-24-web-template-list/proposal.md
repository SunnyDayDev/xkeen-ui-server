# Proposal

## Why

Сейчас после входа пользователь видит только обзор. В [F05 #103](https://github.com/SunnyDayDev/xkeen-ui-server/issues/103) добавляем раздел «Шаблоны», в котором можно узнать, какие черновики сохранены на сервере.

## What Changes

- Из действующей оболочки и по прямому адресу открывается список шаблонов с точными ID и версиями черновиков.
- Список показывает загрузку, пустое состояние и ошибку с ручным повтором.
- Выдача списка использует браузерную сессию администратора. Создание входит в F06, редактирование и просмотр содержимого — в последующие изменения.

## Capabilities

### New Capabilities

- `web-template-list`: чтение списка шаблонов в браузерной консоли.

### Modified Capabilities

## Impact

Навигация оболочки F04, приватный браузерный маршрут F03, метаданные существующих SQLite записей C02/C03 и состояния Pencil. Миграция не нужна.
