## Context

F04 обслуживает HTTPS оболочку, F03 проверяет браузерную сессию, C02/C03 хранят templates(id, draft, version). Для списка нужны только ID и версии. Используем принятые состояния F04 Q5UW7 и QXIyh и иерархию исходного экрана 01 O42w4v.

## Goals / Non-Goals

**Goals:** навигация, прямой адрес, метаданные сохранённых черновиков, загрузка, пустое состояние, ошибка и повтор.

**Non-Goals:** создание, редактор, содержимое, использование роутерами, внешний API и отдельное поле отображаемого имени.

## Decisions

1. Один приватный ответ имеет форму {"templates":[{"id":"branch-east","version":"2"}]}. Сервер переиспользует TLS/Host, cookie и безопасные коды F03. Для чтения CSRF не нужен. Результат закрыт от кеширования. Точный путь /ui/templates добавляется в маршруты оболочки.
2. Прикладной порт получает учётные данные браузерной сессии и возвращает метаданные. Адаптер SQLite проверяет сессию и читает метаданные в общем согласованном снимке. Проверка актуальности и сроков опирается на правила F03. SQL выбирает id, version с COLLATE BINARY, без десериализации черновиков. Доменные инварианты C02/C03 сохраняются.
3. Браузер отображает ID как литеральный текст и версию строкой. Навигация использует History API. При выходе или истечении запоздалый результат запроса не должен снова открыть защищённый список. Состояния Pencil: C0mXcM (список), XoSG3 (пусто), VBn5i (ошибка), KLp26 (загрузка), esEtd (узкий экран). Модель состояний согласуется с Pencil прежде, чем появятся тесты и код интерфейса.

## Risks / Trade-offs

- Строка поддерживает весь диапазон int64 в JavaScript.
- Устаревший ответ при выходе или смене маршрута отфильтровывается по поколению запроса.
- Полный список возвращается одним ответом или целиком отклоняется.
