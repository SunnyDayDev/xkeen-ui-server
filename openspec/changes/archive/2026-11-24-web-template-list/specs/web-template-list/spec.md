## Purpose

Показывать администратору точный список сохранённых черновиков шаблонов в браузерной консоли.

## ADDED Requirements

### Requirement: Доступ к списку по браузерной сессии

Сервис SHALL предоставлять браузеру список по GET /ui/v1/templates через настроенный HTTPS origin. Сессия должна быть действующей при чтении. Запрос не продлевает срок бездействия.

#### Scenario: Список сохранённых черновиков

- **WHEN** администратор с действующей сессией запрашивает список
- **THEN** ответ содержит массив templates с точными ID и версиями всех шаблонов в порядке ID по байтам UTF-8
- **AND** версия передаётся положительной десятичной строкой без округления
- **AND** ответ не содержит содержимое черновиков

#### Scenario: Список пуст

- **WHEN** действующая сессия запрашивает список, а шаблонов ещё нет
- **THEN** ответ содержит пустой массив templates

#### Scenario: Доступ прекращён

- **WHEN** отсутствует действующая браузерная сессия либо запрос направлен вне настроенного HTTPS origin
- **THEN** сервис не возвращает список
- **AND** отсутствие либо истечение браузерной сессии на настроенном origin возвращает 401 signed_out

#### Scenario: Хранилище недоступно

- **WHEN** сервер не может прочитать сессию или полный список
- **THEN** ответ 503 unavailable не содержит данных хранилища или частичного списка

### Requirement: Браузерный раздел шаблонов

Консоль SHALL открывать раздел «Шаблоны» по навигации и по прямому адресу /ui/templates. Возврат и переход вперёд средствами браузера восстанавливают выбранный раздел.

#### Scenario: Загрузка списка

- **WHEN** пользователь с действующей сессией открывает раздел
- **THEN** до получения ответа видна загрузка, после ответа видны точные ID и версии либо пустое состояние

#### Scenario: Ручной повтор

- **WHEN** список не удалось получить
- **THEN** раздел показывает ошибку и позволяет повторить чтение

#### Scenario: Истечение при чтении

- **WHEN** при чтении сервер сообщает об истечении сессии
- **THEN** консоль скрывает защищённые данные и показывает вход
- **AND** успешный вход возвращает в раздел и загружает список для действующей сессии
