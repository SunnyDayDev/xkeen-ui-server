# Приёмка G15

- Первый ARM64 Entware Red остановился на отсутствии серверной команды. Green использует статический release-комплект и точные суммы на локальном HTTPS-зеркале.
- Несовпадающий приватный ключ и занятый порт отвергнуты. На порту оставался настоящий посторонний Go-сервер с тем же синтетическим TLS-сертификатом. Процесс на порту сохранён, ошибочная служба не зарегистрирована.
- Общий GID сначала дал воспроизводимый Red. Green проверяет разные UID/GID двух ролей перед записью профиля.
- Штатный установленный сервер отвечает на HTTPS `/healthz`, отдаёт встроенный HTML и JavaScript. Администратор настроен через штатный F02 CLI и файл владельца 0600. Реальный вход успешен до и после init.d stop/start. Проверены inode SQLite и права владельца, режим ключа TLS 0640 и серверная группа.
- После переноса на принятый G14 полный `sh lab/check-entware-install.sh` и Linux ARM64 vet прошли. Независимое ревью принято. Физических устройств в проверке нет.
