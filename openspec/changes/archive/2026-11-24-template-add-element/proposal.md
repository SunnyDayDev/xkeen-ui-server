## Why

Сейчас оператор может добавить через редактор только первый общий элемент. Сценарию G18 требуется собрать через штатный интерфейс каталог из нескольких секций и правил. [Задача #159](https://github.com/SunnyDayDev/xkeen-ui-server/issues/159).

## What Changes

- В редакторе непустого шаблона появится явное действие «Добавить элемент» с выбором секции и вводом исходного JSON.
- Успешное сохранение создаёт UUID и открывает новый элемент. Остальные записи сохраняются; новое правило добавляется в конец общего порядка.
- При отказе редактор удерживает введённый текст и не повторяет запись автоматически.
