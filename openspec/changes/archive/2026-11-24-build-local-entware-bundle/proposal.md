## Why

[G16 #137](https://github.com/SunnyDayDev/xkeen-ui-server/issues/137) изменена владельцем: собирать комплект Entware локально, когда он нужен.

## What Changes

- Перенести совместимый локальный скрипт сборки кандидата G16, проверить четыре статических бинарника, формат состояния, имена файлов и хеши.
- Описать локальное использование, сверку, принятые ограничения и зависимости G17/G18.

## Capabilities

Действующий формат Entware и обычный CI сохраняются. Это tooling/docs change.

## Impact

Локальная POSIX shell-команда, Git, Go из go.mod, tar, file и SHA-256. GitHub Actions для релиза, OAuth и загрузка не требуются.
