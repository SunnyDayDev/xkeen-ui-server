# Proposal

## Why

Список F05 показывает сохранённые черновики. [F06 #111](https://github.com/SunnyDayDev/xkeen-ui-server/issues/111) даёт администратору первое действие в разделе. Он сможет ввести стабильный ID и создать пустой черновик.

## What Changes

- В разделе «Шаблоны» появляется форма с одним явно подписанным полем идентификатора.
- Успешный запрос сохраняет черновик версии 1 и обновляет список. Повторный ID возвращает конфликт без замены.
- Создание использует браузерную сессию F03 с CSRF и проверкой сессии в транзакции записи. Вкладка удерживает введённый ID при истечении сессии и ждёт явного подтверждения после входа.

## Capabilities

### New Capabilities

- `web-template-create`: создание пустого черновика из браузерного списка.

### Modified Capabilities

## Impact

Форма F06 в разделе F05, браузерный HTTP и проверка F03, API прикладного создания C02, существующая SQLite таблица шаблонов. Новая миграция не нужна.
