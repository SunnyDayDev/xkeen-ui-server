## 2. Полная идентичность и привязки

- [x] 2.1 Для `Identity collisions are detected before exclusions` и `A new shared element can conflict with an existing local element` сначала тесты на уровне полного выбора, затем Red → переиспользование `ValidateRouterLocalIDs` до содержимого → Green/Refactor. Готово: покрыты общие/общие, локальные/локальные и общие/локальные дубли в разных секциях, исключённые и все переданные отключённые элементы, изменение шаблона; обе позиции сохранены, ID не переназначаются, результаты записаны.
- [x] 2.2 Для `Invalid metadata fails even for an empty or excluded selection` и `Unknown modes are not hidden by exclusions` отдельно пройти тест → Red → проверки владельцев/позиций/UUID и режима всех записей → Green/Refactor. Готово: включены пустые и невалидные UTF-8 владельцы/TemplateID, неверные JSON Pointer, неканоничные UUID общих/локальных/ссылок, неизвестный режим под исключением; метаданные имеют приоритет перед заведомо ошибочным JSON и не раскрывают невалидные данные. Зафиксировать фактические результаты.
- [x] 2.3 По `A foreign template cannot supply a binding` и `Missing shared sources are rejected without cleanup` для переопределений и исключений сначала тесты, затем Red → проверка шаблона и существования общего UUID → Green/Refactor. Готово: `source_mismatch` предшествует поиску, `source_not_found` возникает также для UUID, существующего только локально; входные записи не удаляются и не преобразуются. Результаты записаны.
- [x] 2.4 Для `Repeated bindings are errors rather than last write wins` и `An exclusion can coexist with one override` сначала тест каждого случая → Red → проверка повторов списков → Green/Refactor. Готово: `duplicate_override` и `duplicate_exclusion` содержат обе позиции, повтор переопределения под исключением обнаружен, одна запись каждого типа для одного источника допустима; контракт существующего `ValidateOverrideSources` сохранён, результаты записаны.

## 3. Независимые исключения

- [x] 3.1 По `Excluded inherited errors do not block other elements` и `Exclusion hides an invalid replacement without destroying it` писать тесты по одному классу содержимого до соответствующей логики: Red → пропуск сборки после метаданных → Green/Refactor. Готово: исключены проверки сырого JSON, определений, дефолтов, значений и собственного JSON скрытого элемента; UUID/ссылки продолжают проверяться, входы неизменны. Проверить успешный пустой набор при исключении всех общих элементов; результаты записаны.
- [x] 3.2 Для `Repeated selection preserves exclusion across template edits` сначала сценарный тест двух вызовов и другого роутера → Red либо зафиксированный первоначальный Green → минимальная необходимая логика → Green/Refactor. Готово: изменение общего JSON не возвращает исключённый элемент, не меняет локальное содержимое, другой роутер наследует изменение; сохранение после перезапуска не заявлено.
- [x] 3.3 Для `Removing an exclusion restores the current mode` сначала отдельные тесты режима переменных и полной замены → Red либо первоначальный Green → необходимая логика → Green/Refactor. Готово: снятие исключения в новом входном снимке возвращает прежний режим и данные; ошибочная полная замена снова даёт обычную ошибку без fallback. Фактические результаты записаны.
- [x] 3.4 Для `Reset under exclusion does not resurrect the element` сначала тест композиции существующего `TransitionContentOverride` с выбором набора → Red либо первоначальный Green → минимальная логика → Green/Refactor. Готово: сброс не снимает исключение; после снятия используются актуальные дефолты либо возвращается `missing_value`, удалённые данные не восстанавливаются. Результаты записаны.

## 4. Атомарность, диагностика и границы

- [x] 4.1 По `A late content failure yields no partial result` и `Results and diagnostics do not retain mutable input data` каждый небольшой случай начать с теста, подтвердить Red → реализовать атомарный возврат и независимые данные → Green/Refactor. Готово: ошибка после корректных элементов не отдаёт часть набора; мутация входов/выходов, Source и соседних результатов не влияет друг на друга.
