# Проверки F21

Исходный тест не собрался из-за отсутствующего штатного обработчика. После реализации прошли тесты точной JSON-строки, больших чисел в source и defaultSource, decimal int64 версии, выбора ID с пробелом и знаком плюс, плохого UTF-8/повторов query и сильного SHA-256 ETag над байтами ответа. Отдельный настоящий HTTPS-сервер с SQLite прошёл закрытый, защищённый и явно открытый режимы. Устаревшее поколение между admission и чтением получило отказ без данных. Проверено независимым повторным go test -race для wire и HTTPS интеграции.
