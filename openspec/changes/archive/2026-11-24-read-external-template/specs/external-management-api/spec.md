## ADDED Requirements

### Requirement: Внешнее чтение одного выбранного шаблона

Сервис SHALL принимать по HTTPS GET /api/v1/templates/item с единственным точным непустым UTF-8 параметром templateId. Ответ SHALL сериализовать полный редактируемый снимок, в том числе исходный текст и определения переменных, с детерминированными байтами, сильным ETag и Cache-Control no-store, no-transform.

#### Scenario: Пустой сохранённый шаблон
- **WHEN** допущенный клиент читает сохранённый шаблон без элементов
- **THEN** он получает ID, положительную десятичную строку версии и список секций, включая пустые списки без null

#### Scenario: Запрос устарел по праву чтения
- **WHEN** режим доступа или поколение токена изменилось перед транзакцией чтения
- **THEN** сервер возвращает безопасный отказ без снимка и ETag

#### Scenario: Неверный идентификатор или отсутствие записи
- **WHEN** query содержит несколько значений, неверное кодирование или отсутствующую запись
- **THEN** ошибка формы даёт 400, а отсутствующая запись при корректном запросе даёт 404
