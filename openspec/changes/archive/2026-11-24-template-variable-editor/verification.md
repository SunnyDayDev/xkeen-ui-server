# Проверка F08

- Через MCP Pencil перенесены восемь состояний 23б и точечный переход из существующего элемента F07. Независимо проверены отсутствие определений, обязательное значение, семантическая диагностика и узкая компоновка.
- Red: тесты B01 и C03 выявили отсутствие инспектора и узкой операции. Реальный HTTPS вернул 404 на запроектированном маршруте. В Chrome ожидание перехода «Переменные» выявило отсутствие интерфейса до реализации.
- Green: повторно использованы B01 и A08. Структурный отказ оставляет прежнюю версию. Ошибка типа и буквальный null допустимы в черновике и отмечаются как ошибки сборки. Точное число сохраняет значение. Исходный JSON и UUID элемента остаются прежними.
- Реальный Go HTTPS с SQLite проверил целые ссылки, отсутствие и пустой дефолт, смену типа, точное число и диагностику отказа. Chrome проверил значения false, {}, [], сохранность неиспользуемого определения, конфликт и повторный вход без автоматической записи.
- Chrome прямо сравнен с широким и узким состояниями Pencil. Переход на форму и возврат к JSON имеют предусмотренный фокус; горизонтального переполнения при 390 px нет.
- Go test, race и vet, статические Linux AMD64/ARM64, воспроизводимые Vite-ассеты и OpenSpec strict прошли. Сквозной процессный тест прошёл в отдельном Entware aarch64-k3.10 под LinuxKit 7.0.14 с лимитом 256 МиБ, пик 183226368 байт, OOM-убийств нет.
- Независимая проверка кода подтвердила общее правило B01, сохранение чужих элементов, приватный авторизованный снимок и условный writer; целевой Go race пройден повторно.
- На совмещённом Pencil поверх F09 перенесены только восемь состояний 23б и два перехода F07. Проверены рендеры актуальных F07, F08 и F09 и совместная browser-сборка.
