## Why

A08 автоматически объявляет переменные по ссылкам. После редактирования сырого JSON администратору нужно настроить тип и значение по умолчанию для одного блока. [F08 #100](https://github.com/SunnyDayDev/xkeen-ui-server/issues/100).

## What Changes

- Показывать текущие определения с точным именем, сохранённым JSON-дефолтом, типом и производной обязательностью персонального значения.
- Сохранять изменённые типы и дефолты выбранного элемента с проверкой структуры и версии. Пустой дефолт остаётся допустимым при смене типа. Отдельный флаг обязательности не вводится.
- Показывать структурный отказ и отдельно диагностику готовности определения по B01. Структурно корректный черновик может остаться неготовым к сборке.
- Сохранять порядок определений, UUID и сырой JSON элемента. Имена, впервые объявленные F07, появляются после сохранения сырого JSON. Настройка персональных значений и публикация выходят за границу F08.
