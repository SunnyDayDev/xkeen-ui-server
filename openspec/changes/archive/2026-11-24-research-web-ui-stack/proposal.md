# F01. Исследование стека веб-интерфейса

## Why

[F01 / issue #45](https://github.com/SunnyDayDev/xkeen-ui-server/issues/45) требует предложить способ построения UI и его поставки на сервер в Docker и Entware. Для решения важны компоненты макета и редактирование несохранённого черновика, а также размер и зависимости на стороне сервера.

## What Changes

- Сравнить Svelte + Vite, React + Vite и Go templates + htmx.
- Сверить сценарии и повторяемые компоненты с макетом через MCP Pencil.
- Измерить небольшую одинаковую пробу и проверить статическую поставку из Go-бинарника.
- Записать рекомендацию и границы проверки.
