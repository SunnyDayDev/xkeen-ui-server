# Приёмка исследования F01

[Issue #45](https://github.com/SunnyDayDev/xkeen-ui-server/issues/45). [Сравнение, результаты замеров и рекомендация](../../../../docs/web-ui-stack-research.md).

## Как повторить

Из корня репозитория запустить команды ниже. Нужны Go 1.27.1, Node 26.5.0 с npm 11.17.0, установленный Chrome или Chromium и Docker с ARM64-контейнерами. Переменная `CHROME_EXECUTABLE` содержит путь к установленному браузеру. Если указанное имя есть в PATH, можно использовать `CHROME_EXECUTABLE="$(command -v chromium)"`. Сборка скачивает npm-зависимости из публичного реестра по lockfile и работает в отдельном временном каталоге.

```sh
docker build --platform linux/arm64 --tag xkeen-router-lab:dev lab
RUN_CONTAINERS=1 CHROME_EXECUTABLE="$CHROME_EXECUTABLE" \
  sh openspec/changes/archive/2026-11-24-research-web-ui-stack/probe/run.sh
```

Без `RUN_CONTAINERS=1` выполняются сборки, замер и браузерные проверки. Для контейнеров используется Alpine 3.24.2 и лабораторный Entware ARM64. Проверка монтирует только статический бинарник, ограничивает сеть контейнера локальной петлёй и проверяет HTML, JavaScript, ответы статуса и отказ для отсутствующего ресурса.

## Фактический результат

- Через MCP Pencil просмотрены группы Design System и экраны 02, 04, 06, 08 и 11. Сверена связь компонентов и состояний с [картой макетов](../../../../docs/design.md).
- Сборка из временного каталога прошла с точными зависимостями. Браузер подтвердил для трёх вариантов клавиатурное действие, обновление статуса и точный сохранённый текст в поле между действиями.
- Все шесть контейнерных запусков прошли. Проба проверила Go ARM64 ELF в Alpine и Entware без Node, сети наружу и рабочих томов.
- Строгая валидация OpenSpec и проверка локальных ссылок прошли. Использован `skip_specs: true`, поскольку работа исследовательская.

Проверка относится к минимальной пробе. Потребление памяти, размер продуктового редактора, матрица браузеров и физические устройства остаются последующими проверками.
