# Проверка F18

- Штатный HTTPS-тест дал Red на неопределённом маршруте. Green подтверждает строгую форму обеих фаз, no-store, запрет доступа без F03, нулевой состав и отсутствие записи до подтверждения. Подписанная квитанция принимается только для того же шаблона, сессии, версий и срока. Допустимый длинный ID создал квитанцию за пределом HTTP-лимита в Red. После привязки к SHA-256 точных байтов ID квитанция имеет ограниченный размер.
- C07 и SQLite проверены на полной группе, включая скрытого офлайн-участника с ожидающим назначением B и действующим A. Общая подготовка обеих фаз учитывает действующие персональные списки XKeen. Непустой недоступный обход отказывает всей группе, а нулевой состав может принять общий снимок. Восемь целевых повторений с race прошли.
- Chrome и реальный сервер использовали два штатных синтетических назначения C06, заданные в фикстуре метки контакта и изолированный Xray. Проверены Red отсутствующего входа, независимое подтверждение, узкая ширина 320 px, полный состав и точные изменения файлов, отказ Xray, смена версии между фазами и отсутствие частичных желаемых ревизий.
- Потеря ответа после успешной записи позволяет только безопасно перечитать текущее состояние. Задержанный ответ 200 до повторного входа выявил исчезновение «Проверить состояние» в Red. Green очищает квитанцию и данные и сохраняет только возможность явной проверки. Без изменения байтов принимается новая версия общего снимка, а номера желаемых ревизий сохраняются. Результат C07 отделён от E08.
- Полный Go, vet и race прошли. ARM64 Entware прошёл восемь проверок штатного процесса, включая F18. Пик памяти cgroup 189644800 байтов, oom_kill 0.
- Независимое ревью Pencil, C07/F03, HTTP и браузерных переходов завершено. Обязательные CI проверяют точный PR до слияния и закрытия #153.
