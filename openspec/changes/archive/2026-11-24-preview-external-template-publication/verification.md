# Проверка внешнего предпросмотра

Штатный процесс HTTPS с SQLite вернул 404 при действительном допуске в Red. После подключения маршрута он выдал точный план для нулевого состава, проверил строгую форму запроса и отклонил использование внешней квитанции в веб-консоли.

На том же процессе с реальным изолированным Xray C07 вернул обоих действующих участников, включая скрытого роутера без связи. В обоих случаях прежняя желаемая ревизия 1 сохранилась. Xray отклонил ошибочный каталог без выдачи квитанции. Отдельная проверка отозвала поколение F20 во время проверки и получила отказ после проверки, без плана и побочных эффектов. Целевой race повторён восемь раз. Пройдены полный Go и vet, совместный реальный Chrome F18 и восемь проверок ARM64 Entware. Пик памяти cgroup 187957248 байтов, oom_kill 0. Независимое ревью завершено.
