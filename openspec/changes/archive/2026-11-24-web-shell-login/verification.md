# Проверка F04

Pencil 17–19 переиспользованы. Добавлены и независимо проверены авторизованные экраны `Q5UW7` и `QXIyh`. В Chrome визуально проверены активная оболочка и форма входа на ширине 360 px, с видимым фокусом и без горизонтальной прокрутки.

- Red Go-процесса вернул 404 на `/ui/`. Green проверил выдачу встроенных HTML/JS при правильном TLS origin, no-store для HTML, чужой Host, статический 404 и неизменный начальный статус F03.
- Браузерный Red не нашёл экран настройки на существовавшем бинарнике. Green использовал реальный Go, HTTPS с доверенным синтетическим открытым ключом, локальные команды F03 и временную SQLite. Проверены настройка, ожидание, неверный пароль, Enter, ограничение попыток, недоступность logout, повторный вход и выход.
- Независимое ревью обнаружило потерю прежнего фокуса. Браузерный Red сохранил синтетический буфер, но вернул фокус в контейнер. Green вернул фокус к сохранённому полю и подтвердил его значение и отсутствие дополнительных POST. Полноценный редактор остаётся отдельной задачей.
- Полные Go, race, vet и Linux ARM64/AMD64 без cgo прошли. Тот же Go-процессный тест выдачи вложенного UI прошёл в закрытом Entware ARM64 без Node. Повторный Vite build побайтно совпал со встроенными файлами.

```sh
npm --prefix web ci
npm --prefix web run build
go build -o .build/xkeen-ui-server ./cmd/xkeen-ui-server
CHROME_EXECUTABLE="$CHROME" XKEEN_TEST_SERVER_BINARY="$PWD/.build/xkeen-ui-server" npm --prefix web run test:browser
```
