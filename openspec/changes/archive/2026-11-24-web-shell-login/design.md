## Context

F01 согласовал Svelte + TypeScript + Vite и включение статических файлов в Go. F02 определяет локального владельца, отдельную веб-сессию и сохранение открытого буфера. F03 обслуживает статус, вход, выход и явное действие через тот же защищённый origin.

## Decisions

1. **Путь и доставка.** `/ui/` обслуживает HTML и хешированные файлы сборки только на включённом origin F03 с тем же точным правилом Host и TLS. HTML не кэшивается. Неизвестный статический файл получает 404. Страницы и API не подменяют друг друга. Ни один путь /ui/v1/ не получает HTML оболочки. Отсутствие сессии открывает страницу входа, а данные прикладных операций остаются под авторизацией. Статика не содержит паролей, токенов, состояния аккаунта или клиентской телеметрии. Бинарник включает Vite-результат через `go:embed`. Lockfile, воспроизводимый build и проверка соответствия встроенных файлов входят в задачу.
2. **Сессия.** Браузер использует тот же origin и F03 JSON. Начальный GET определяет отсутствие настройки, выход или активную сессию. Вход принимает результат F03 бессекретно для журналов и не сохраняет пароль после отправки. CSRF хранится только в памяти. На время запроса форма занята, выводит понятный ответ для неверного пароля, ограничения попыток и недоступности. Выход выполняет подтверждённую серверную операцию. Ошибка транспорта не отображается как успешный выход. Пассивный контроль статуса и проверка при возвращении вкладки не продлевают срок. Ответ 401 signed_out закрывает защищённую область. Ответ 403 invalid_csrf вызывает безопасную перепроверку статуса без автоматического повтора изменяющего запроса. При сетевой ошибке открытый буфер удерживается. Отдельная операция продления доступна только для реальных явных действий, поэтому F04 не имитирует активность редактора и не вызывает её по навигации или опросу. Будущие действия повторно проверяются сервером.
3. **Вкладка и навигация.** Активная оболочка предоставляет ссылку на доступный экран и выход, с однозначным текущим состоянием. Только реализованные места доступны в навигации. Сохранение черновика остаётся операцией будущего редактора; F04 позволяет вложенной области удерживать её локальное состояние при истечении без скрытого повторного запроса. При первом открытии без сессии защищённая область не создаётся. После истечения активные элементы недоступны, а после входа восстанавливаются без переотправки и с возвратом фокуса.
4. **Макет и доступность.** Использовать подтверждённые в F03 состояния Pencil 17–19 (QAYZb, D8sbkB, WR9L7, W9Ywe, h0Oj5q, b3huic, QIylS, s8V3kI, kQu6M, S3XAy). Стили формы опираются на Tokens, Input/FormField, Button. Перед кодом добавлены и проверены активные экраны Q5UW7 и QXIyh. Пароль поддерживает автозаполнение браузера и Enter, статус читается через live region, фокус видим и возвращается после изменений. Ограничение браузерных анимаций соблюдает предпочтения системы.

## Risks / Trade-offs

- Оболочка использует тот же защищённый origin и собственный кэш статических ассетов. Изменения в таймаутах или правилах авторизации остаются в F03.
- Сохранение памяти вкладки подтверждается на шве оболочки. Редактор и сохранение его данных проходят отдельные задачи. При закрытии или перезагрузке вкладки эта область не обещает восстановление.
