## ADDED Requirements

### Requirement: Transport-agent updates retain service identity and operating settings

Установленная служба SHALL обновляться до явно выбранного проверенного выпуска, сохранив HTTPS origin, CA, UID/GID и сохранённый ключ. Точный повтор установленного выпуска SHALL оставлять текущий экземпляр без перезапуска.

#### Scenario: An incomplete update leaves the current agent running

- **WHEN** загрузка файла нового выпуска прерывается либо ожидаемая сумма не совпадает
- **THEN** прежний процесс, профиль, поколение и приватное состояние остаются действующими

#### Scenario: A verified successor authenticates with the previous key

- **WHEN** новый проверенный выпуск допускается к установке, старый процесс штатно остановлен и новый запущен
- **THEN** новая служба подтверждает аутентификацию для того же RouterID, а приватное состояние и эффективный профиль сохраняются

#### Scenario: A failed update returns to the previous confirmed generation

- **WHEN** новый выпуск не подтверждает запуск
- **THEN** прежнее поколение возвращается только при доказанном отсутствии чужого или неопределённого процесса
- **AND** ошибка запуска и результат локального восстановления сообщаются отдельно, ключ и настройки остаются сохранёнными

#### Scenario: An interrupted update is resolved before automatic startup

- **WHEN** служба запускается после прерывания смены поколения
- **THEN** продолжение использует защищённую запись о старом и новом поколениях, сохраняет подтверждённое поколение и блокирует запуск при неопределённом состоянии
