# Приёмка G14

- Отдельное зеркало HTTPS обслужило точные версии с закреплёнными манифестами. До реализации сценарий Red остановился на отсутствии команды обновления. После реализации усечённый HTTPS-ответ сохранил установленный процесс и ссылку поколения.
- Точный повтор не перезапустил службу. Успешная смена поколения запустила реальный агент с теми же RouterID, ключом, origin и правами. Невалидный для агентского запуска проверенный ELF привёл к возврату прежнего поколения.
- Синтетический сервер временно остановлен сигналом, а настоящий процесс установки прерван после записи идентичности кандидата. До исправления Red показал отсутствие квитанции до готовности. После штатного init.d start прежний выпуск восстановлен.
- В отдельном Entware процессная проба воспроизвела Red повторного запуска после ошибки fsync после rename и обоих отсутствующих логических полей. После исправления запись сохраняется до подтверждённого fsync, неполное намерение отклоняется.
- Независимое ревью пройдено. Воспроизведение `sh lab/check-entware-install.sh`, только ARM64 Entware в Docker и синтетические HTTP(S) данные.
