## Why

Внешнему клиенту нужен штатный способ добавить буквальный локальный JSON в полный персональный порядок одного роутера. [Задача #181](https://github.com/SunnyDayDev/xkeen-ui-server/issues/181).

## What Changes

Добавить авторизованное чтение полного порядка и условную вставку локального правила по F14.

## Capabilities

### New Capabilities

- `external-router-local-rule-addition` — Добавить авторизованное чтение полного порядка и условную вставку локального правила по F14.

## Impact

Существующий F20, вариация условной записи C04 и документация HTTP.
