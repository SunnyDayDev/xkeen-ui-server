## Purpose

Внешний клиент условно редактирует полную замену одного общего элемента роутера.

## ADDED Requirements

### Requirement: Replacement transitions are explicit and conditional

Внешний API SHALL применять F20, полное предусловие и переходы B05 к одному общему UUID роутера. Удаление прежних данных SHALL требовать явного подтверждения возврата или сброса.

#### Scenario: Literal content retains inactive values
- **WHEN** клиент передаёт точный ETag и допустимый буквальный JSON
- **THEN** новая замена сохранена точно, прежние значения остаются неактивными, UUID и отдельные настройки сохраняются

#### Scenario: Return and reset change distinct data
- **WHEN** клиент условно подтверждает возврат в переменные или полный сброс
- **THEN** возврат удаляет только свой JSON, а сброс удаляет персональные данные элемента, сохраняя отдельное исключение

#### Scenario: Invalid, stale or revoked input is atomic
- **WHEN** нет подтверждения, исходник недопустим, основание изменилось или допуск отозван
- **THEN** черновик остаётся прежним
