# Сквозное испытание G18

## Среда и исходный комплект

Docker Desktop, Linux 7.0.14-linuxkit aarch64, Entware aarch64-k3.10, Xray 26.3.27. Go 1.27.1. Локальная сборка скриптом G16 из коммита `b5b5794`, синтетический тег `v0.0.141`, временное HTTPS-зеркало со структурой выпуска и сверкой SHA-256. Физические узлы и публикация выпуска в GitHub не использовались.

Сервер установлен из комплекта. F02 провёл первичную настройку новой базы из приватного файла. Браузер выполнил авторизацию, создал шаблон с несколькими элементами, задал обязательное персональное значение, подготовил первое назначение через реальный отдельный mTLS-валидатор и выпустил одноразовое приглашение. Обычная установка управляемого агента с этим приглашением завершилась штатным стартом через init.d.

## Регрессия установки

Первый полный запуск обнаружил отказ E02: процесс установки передавал `umask 077`, из-за чего непривилегированный Xray не мог выполнить проверенный файл внутри изолированного корня. Изолированный процессный тест `TestRunnerStageHasExactModesWithPrivateInstallerUmask` воспроизвёл прежние режимы 0700, 0400 и 0500 до исправления. После задания точных режимов внутри приватного каталога внешний барьер сохранился, отдельный ARM64 тест и полный операторский сценарий прошли.

`go test ./...`, `go vet ./...`, `go test -race ./cmd/xkeen-ui-server -run InstalledAgentLink -count=8`, `sh -n lab/check-installed-entware-flow.sh` и `node --check web/installed-entware-flow.mjs` — PASS.
