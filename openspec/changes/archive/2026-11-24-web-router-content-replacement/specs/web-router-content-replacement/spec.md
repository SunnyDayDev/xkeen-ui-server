## Purpose

Редактировать полную замену блока роутера в авторизованной браузерной области центрального сервера.

## ADDED Requirements

### Requirement: A router replacement replaces only its selected block

Браузер SHALL сохранять собственный JSON одного общего элемента по неизменному UUID. При переходах SHALL применяться B05. Отмена формы SHALL сохранять прежнюю запись. Явный полный сброс SHALL очищать переопределение, сохраняя идентичность и отдельное исключение.

#### Scenario: Variables survive activation of literal replacement
- **WHEN** владелец явно сохраняет свой структурно допустимый JSON вместо наследуемого
- **THEN** используется буквальный JSON, сохранённые персональные значения остаются неактивными

#### Scenario: Cancellation and full reset are distinguishable
- **WHEN** владелец отменяет редактирование либо отдельно подтверждает полный сброс
- **THEN** отмена не пишет; сброс удаляет переопределение и не снимает исключение

#### Scenario: An explicit return restores inherited variables
- **WHEN** владелец подтверждает возврат из полной замены в переменные
- **THEN** собственный JSON удаляется из персонального черновика этого UUID, сохранённые значения снова относятся к текущим определениям
- **AND** ошибки готовности видны отдельно, а исключения и общий порядок сохраняются

#### Scenario: A stale edit or invalid replacement leaves the record intact
- **WHEN** меняется область, версия или сессия либо собственный JSON содержит синтаксическую ошибку
- **THEN** запись отклоняется целиком, открытый текст остаётся доступен для явного продолжения

#### Scenario: A valid literal can contain template-like text
- **WHEN** владелец сохраняет допустимый буквальный JSON, включая JSON null или строку вида `${name}`
- **THEN** собственный текст сохраняется точно, включая экранирование и форматирование, без интерпретации ссылок
