## Why

Поддержать существующую замену и явный переход B05 для одного общего блока, сохранив UUID, неактивные значения и отдельность исключения. Отмена формы не пишет; полный сброс очищает переопределение. Отразить потерю собственного JSON при сохранённом возврате в режим переменных по B05. [F13 #148](https://github.com/SunnyDayDev/xkeen-ui-server/issues/148).

## What Changes

Выделить один сценарий в существующей браузерной области, сохранив границы хранения и публикации.
