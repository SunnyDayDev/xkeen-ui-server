## Context

Поддержать существующую замену и явный переход B05 для одного общего блока, сохранив UUID, неактивные значения и отдельность исключения. Отмена формы не пишет; полный сброс очищает переопределение. Отразить потерю собственного JSON при сохранённом возврате в режим переменных по B05. Используются F12, B03–B06, C04.

## Decisions

Черновик и связь с общим UUID наследуют точный контекст и атомарную запись F12. B05 является единственным владельцем переходов: замена принимает буквальный JSON, включая поддерживаемый A08 корневой null, сохраняет неактивные персональные значения. Возврат в режим переменных заново использует текущие определения и нужные диагностики; сохранённое собственное содержимое при этом очищается по B05. Незавершённое переключение не пишет. Кнопки отмены формы и полного сброса различаются: сброс явно удаляет сохранённые тип переопределения, JSON и персональные значения, сохраняя общее происхождение/отдельное исключение. Pencil 10/11, сохранение, отмена, предупреждение о потере замены и конечные состояния.

Открывать «Свой JSON» из выбранного элемента F12 с точными RouterID и UUID. Уже сохранённый собственный JSON загружается дословно. Если действует наследование, редактор начинает с пустого поля и отдельной кнопки сохранения. Выдача содержимого, определения и допуск принадлежат только одному выбранному источнику в авторизованном снимке. Использовать редактор точного текста F07/F12. Черновик в открытой вкладке переживает повторный вход; неопределённый ответ требует перечитать состояние.

При подтверждении возврата в переменные B05 убирает сохранённый собственный JSON и оставляет значения. Сброс отдельной подтверждаемой командой удаляет оба вида персональных данных этого UUID. Отмена любого диалога или простое открытие редактора не создаёт записи. Начальное наследование, действующая замена, ошибки структуры, конфликт полномочий, подтверждения возврата и сброса, узкий экран — отдельные состояния Pencil.

Обе операции используют приватный `/ui/v1/routers/replacement` с обязательными точными `routerId` и `elementId`. GET возвращает режим, UUID, наличие сохранённой записи и точный `source`, если действует замена. POST требует основание F12 (три поколения и ID принятого шаблона) и команду `replace`, `variables` или `reset`. Поле `source` — строка буквального JSON и требуется только для `replace`. В ответе сохраняется прежний UUID и возвращается сохранённое состояние. Ссылка обратно открывает тот же элемент формы F12, где остаются определения и диагностика возврата.

## Risks / Trade-offs

Сетевой отказ и неполное доказательство не подтверждают изменение. Места ошибок и безопасные диагностические результаты сверяются с актуальными входами на штатном сервере.
