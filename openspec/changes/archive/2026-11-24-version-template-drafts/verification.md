# C03 — проверка реализации

Дата проверки — 2026-11-24. Критерии приёмки — [issue #41](https://github.com/SunnyDayDev/xkeen-ui-server/issues/41).

| Критерий | Результат |
| --- | --- |
| Версия при создании, чтении и обновлении схемы | Новый черновик возвращается с версией 1. Миграция v4 обновляет базы v2 и v3. Прежние ID и байты шаблонов сохраняются. Снимок настроек роутера v3 и его персональные ссылки сохраняются после миграции и последующей замены элемента шаблона. |
| Атомарная замена и перезапуск | Условная замена сохраняет новый полный снимок под исходным ID и повышает версию на 1. Сохранение того же содержимого повторно повышает версию. Повторное открытие читает содержимое и последнюю версию. |
| Конфликт и безопасный отказ | Из двух записей через независимые SQLite-подключения с одним ожидаемым номером фиксируется одна. Устаревший вызов получает `version_conflict`. Отсутствие ID, недопустимый кандидат, исчерпание `int64` и ошибка записи различимы. Неудачная операция сохраняет предыдущие данные. |
| Артефакты и фактические проверки | Дельта, техническое решение, задачи и этот отчёт приложены. Контракт использования описан в [модели конфигурации](../../../../docs/configuration-model.md#реализованный-шаг-c03). |

## Red и Green

- Прикладные тесты были добавлены до реализации. На C02 отсутствовали тип снимка с версией, отдельный конфликт и операция замены, поэтому новые сценарии не компилировались. После добавления операций и переиспользования подготовки C02 прикладные тесты прошли, включая неизменность отказов и независимость результата.
- SQLite-тесты миграции и замены были добавлены до реализации репозитория. Существующий адаптер не удовлетворял версионированному порту. С новым адаптером без v4 чтение файла с v2 возвращало ошибку из-за отсутствующей колонки. Отдельная проба файла v3 показывала отсутствие v4 в истории. После добавления миграции все сценарии прошли.
- Прямой вызов двух записей к одному файлу повторён 100 раз. Каждый раз одна запись получала версию 2, а вторая — конфликт. При новом открытии проверялся снимок победителя.
- Независимое ревью проверило условие записи, классификацию отказа в той же транзакции и тесты. Повторный запуск прикладных и SQLite-тестов рецензентом прошёл.

## Команды

- Go 1.27.1 на Darwin ARM64. `go test ./... -count=1`, `go test -race ./... -count=1`, `go vet ./...`, `go test ./internal/storage/sqlite -run '^TestTemplateVersionsConcurrentReplace$' -count=100` и строгая проверка OpenSpec прошли.
- Сборки Linux ARM64 и AMD64 с `CGO_ENABLED=0` прошли. `sh lab/check-server-storage.sh` выполнил тесты миграции и конкурентной записи и запустил сервер в изолированном Entware aarch64. Среда — Linux 7.0.14-linuxkit, busybox 1.38.0-5, libc 2.27-12, встроенная SQLite 3.53.4. Проверка относится к контейнеру.
