## Why

Два потребителя могут прочитать один черновик шаблона и подготовить разные правки на этой основе. [C03 / issue #41](https://github.com/SunnyDayDev/xkeen-ui-server/issues/41) добавляет условную замену к созданию и чтению [C02 / issue #39](https://github.com/SunnyDayDev/xkeen-ui-server/issues/39), чтобы позднее сохранение не потеряло ранее принятые изменения.

## What Changes

- Возвращать версию вместе со снимком при создании и чтении. Существующие шаблоны получат начальную версию при обновлении схемы с сохранением прежних данных.
- Принимать полный кандидат и обязательную ожидаемую версию. При совпадении сохранять снимок и следующий номер вместе.
- Возвращать отдельный результат для устаревшей версии, отсутствующего шаблона и недопустимой правки. Два сохранения с одной ожидаемой версией дают один успех.

## Impact

Изменятся внутренний сервис хранения шаблонов, SQLite-адаптер и последовательность миграций. Связь [C04 / issue #38](https://github.com/SunnyDayDev/xkeen-ui-server/issues/38) сохраняет стабильный ID шаблона. Публикация, желаемые ревизии, HTTP и UI относятся к последующим изменениям.
