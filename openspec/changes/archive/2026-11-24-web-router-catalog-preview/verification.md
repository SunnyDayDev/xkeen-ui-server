# Проверка F17

- Первоначальный тест штатного HTTPS-сервера остановился на отсутствии API с ответом 404. После подключения сервиса сервер проверяет F03/G05, сохраняет точную исходную ревизию и возвращает точное B12-значение 9007199254740993 в собранном файле. Синтетическая некорректная запись вызывает 422 с диагностикой без файлов.
- При имитации отозванной сессии после чтения неуспешная сборка изначально открывала устаревшую диагностику. После общей повторной проверки и для успеха, и для ошибки возвращается отказ доступа.
- SQLite проверяет несовпадающий C04 после чтения, независимость действующей ревизии от неиспользованного C04, скрытие роутера и отзыв сессии. Восемь повторений с race прошли.
- Chrome мог пройти до карточки, но останавливался на отсутствующей ссылке «Файлы». После добавления он проверяет точный текст, загружает Blob из того же ответа и сравнивает его побайтово, включая неизвестное поле и число 9007199254740993. Узкая ширина 320 px, ошибка B12, скрытый роутер, запоздалый результат после отзыва и отсутствие автоматического запроса после входа проверены. Отдельный прямой переход воспроизвёл пропущенный путь оболочки, итоговый прогон прошёл с обеими точками входа.
- Полный Go, vet и race прошли. В изолированном ARM64 Entware пройдены все восемь проверок, в том числе штатный процесс с F17. Пик памяти cgroup 186314752 байта, oom_kill 0.
- Независимое ревью Pencil, сервера и браузера завершено. Обязательные CI проверяют точный PR до слияния и закрытия #152.
