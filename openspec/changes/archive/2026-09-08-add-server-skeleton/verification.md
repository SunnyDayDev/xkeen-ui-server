## Исправления проверочного окружения

- Официальный tar.gz Go 1.27.1 для macOS ARM64 возвращал 404. Использован официальный proxy той же версии с проверкой суммы; версия не заменялась.
- Первый запуск сетевых тестов был отклонён sandbox (`bind: operation not permitted`). Он не засчитан как Red. После разрешения loopback тесты упали по отсутствующему поведению, указанному выше.
- Первая ручная проверка повторного bind в Python не использовала SO_REUSEADDR и столкнулась с TCP TIME_WAIT после успешного завершения сервера. Повторная проверка с поведением bind, соответствующим Go listener, прошла.
- Первая Entware-проба использовала `sleep 0.1`, неподдерживаемый данным BusyBox. В воспроизводимой команде используется `sleep 1`; повторная проба прошла. Неудачный контейнер также удалён через `--rm`.

## Границы

Entware-проба запускала только бинарник в отдельном контейнере с `--network none`, без публикации портов и дополнительных capabilities. Смонтирован только read-only бинарник; рабочие volumes и конфиги лаборатории не подключались. Xray/XKeen-сценарии не изменялись и повторно не запускались.

Проверка таймаута и активного запроса использует управляемые handlers на внутреннем lifecycle-интерфейсе; продуктовый сервер не содержит тестовых маршрутов. Физический роутер не подключался. SQLite, UI, агент, установщик и нагрузочные измерения этим результатом не подтверждаются.
