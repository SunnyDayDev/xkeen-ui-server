# Завершение контракта B03

Задача: [B03 #18](https://github.com/SunnyDayDev/xkeen-ui-server/issues/18); обзорная [#1](https://github.com/SunnyDayDev/xkeen-ui-server/issues/1). Issue создана и прочитана обратно, её критерии соответствуют контракту.

## Область и результат ревью

2026-09-21 пользователь выбрал выполнение `define-content-inheritance` после просмотра предложения. Проверены все семь требований и 24 сценария [дельты](specs/configuration-content-inheritance/spec.md) относительно A07/A08/B01/B02 и критериев B03 из roadmap. Сохранение значений при смене режима и полный сброс были согласованы отдельно; независимое исключение принято в составе выполнения подготовленного change. Противоречий с действующими контрактами не найдено.

Выбор содержимого не подтверждает готовность Xray. Полная замена не использует определения/значения шаблона; сохранённые неактивные значения снова проверяются при возврате. Исключение сохраняет режим и данные, а сброс содержимого не снимает исключение. Проверка уникальности охватывает полный набор до исключений.

Это завершение проектирования, без реализации B04–B06. Код, тесты функций, Go-зависимости, адаптер записи элемента и макет не меняются. Red/Green, Go-тесты и пробы Xray в рамках B03 не выполнялись и не заявляются.

## Критерии B03 и сценарии

| Критерий | Требования | Проверенное поведение |
| --- | --- | --- |
| Два режима | Content inheritance uses the current source element; Full replacement selects only personal JSON | Актуальный JSON/дефолты, персональные значения, полная замена без слияния и повторной интерпретации |
| Переключение | Mode switches retain personal variable values | Возврат значений; смена типа, удаление определения и новая обязательная переменная дают ошибки без потери данных |
| Отмена переопределения | Reset removes all content override data | Полный сброс, возможная незаполненность, отсутствие восстановления удалённых данных; отмена несохранённой правки отлична от сброса |
| Локальный элемент | Local elements remain independent additions | Добавление, независимые теги, коллизия с исключённым общим UUID |
| Сохранённое исключение | Shared exclusions survive repeated content selection | Повторная сборка, полная замена под исключением, сброс без снятия исключения |
| Сквозные инварианты | Content operations preserve order and report atomic failures | Независимый порядок, UUID, повторные переопределения, атомарность и безопасная диагностика |

Для каждого сценария будущей реализации проверен порядок test-first: тест по spec через публичную границу, подтверждённый поведенческий Red, минимальная логика и Green, рефакторинг/повторная проверка, фактический отчёт. Особо выделены атомарность, копирование буферов и диагностика без данных. C04 получает интеграционные проверки сохранения режима, неактивных значений и исключения после перезапуска. Будущие UI-изменения сначала обновляют/проверяют Pencil, затем проходят тесты, реализацию и визуальную сверку. Эти планы не являются результатами выполненных тестов.
