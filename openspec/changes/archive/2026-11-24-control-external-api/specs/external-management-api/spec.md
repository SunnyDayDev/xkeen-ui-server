## ADDED Requirements

### Requirement: Владелец условно меняет состояние программного доступа

Владелец SHALL видеть текущие положения переключателей, наличие токена и версию настроек. Изменение положений и выпуск общего токена SHALL проверять действующую сессию владельца, CSRF и ожидаемую версию в одной операции записи.

#### Scenario: Другая вкладка успела заменить токен
- **WHEN** владелец отправляет изменение со старой версией
- **THEN** операция возвращает конфликт, оставляет актуальный токен и настройки, интерфейс предлагает перечитать их

#### Scenario: Секрет показан владельцу
- **WHEN** владелец выпускает или подтверждает замену токена
- **THEN** интерфейс показывает выданное значение для копирования один раз и убирает его при закрытии, выходе или утрате доступа к сессии
- **AND** последующее чтение возвращает только наличие токена

#### Scenario: Владелец получает ответ неизвестного исхода
- **WHEN** ответ после выпуска потерян
- **THEN** повторное чтение показывает актуальное состояние и ручную возможность замены без автоматического повторного выпуска
