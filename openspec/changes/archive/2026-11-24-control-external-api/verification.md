# Проверки F20

В отдельной SQLite-базе проверены закрытый миграционный default, открытый и защищённый режимы, отзыв старого токена, CAS двух одновременных выпусков и сохранение состояния при переоткрытии. Проверка выполняется после захвата транзакции, включая срок сессии. Версия передаётся десятичной строкой для положительных int64, в том числе 9007199254740993 и MaxInt64.

До реализации UI через Pencil подготовлены исходное состояние, сохранённый токен, однократный показ, подтверждение замены и открытый режим. Все пять экранов визуально проверены. В настоящем Chrome со штатным HTTPS-сервером проверены переключатели, выпуск, ротация, уничтожение DOM поля после истечения сессии и поздний ответ выдачи после потери сессии. Секрет не сохраняется браузером в storage. Нативные race-тесты проверили доступ/конкуренцию, независимый reviewer C01 повторил проверки и отдельно перепроверил границу int64.

После приёмки F05 (#114) операции Pencil для F20 воспроизведены поверх её файла из main 971c0603. Подтверждены пять F05-экранов и три дополнительных F20-состояния w2xWJ, DlV5Y, g3qyxy; проверены скриншоты списка и всех пяти состояний настроек. Совмещённая оболочка сохраняет /ui/templates и добавляет /ui/settings. Общий сценарий браузера F04/F05/F20 повторно прошёл.
