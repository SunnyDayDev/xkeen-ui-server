## Why

После A06 и B01 ядро умеет выбирать значения и подставлять целые ссылки, но ещё пропускает `null` сырого шаблона и не реализует полный синтаксис A05. B02 завершает этот контракт и соединяет проверки в одной операции, возвращающей JSON одного элемента либо ошибки.

Связь с трекером: B02 в [обзорной issue #1](https://github.com/SunnyDayDev/xkeen-ui-server/issues/1) и [плане](../../../../docs/roadmap.md#2-чистое-ядро-конфигурации). Зависимость — завершённая [B01, issue #14](https://github.com/SunnyDayDev/xkeen-ui-server/issues/14); исходный контракт — [A05, issue #6](https://github.com/SunnyDayDev/xkeen-ui-server/issues/6). Выделенная задача реализации — [B02, issue #16](https://github.com/SunnyDayDev/xkeen-ui-server/issues/16), создана с критериями этой дельты. Обзорная #1 остаётся отдельной задачей.

## What Changes

- Добавить единую операцию сборки JSON одного элемента: ID для диагностики, сырой шаблон, определения и персональные значения → самостоятельный результат либо ошибки без частичного JSON.
- Дополнить подстановку проверкой `null` сырого шаблона, однопроходным `$$`, распознаванием некорректных ссылок и отклонением частичной интерполяции; сохранить буквальные ключи и непреобразуемые данные переменных.
- Использовать существующую подготовку B01 для проверки всех определений, персональных значений и дефолтов, включая неиспользуемые и невыбранные. Сборка не объявляет переменные автоматически.
- Сохранить допустимость черновиков A08: строгие правила сборки не переносятся в сохранение или общий JSON-парсер.
- Закрепить диагностику новых случаев и сценарии сквозной проверки контракта A05 через единую операцию.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `configuration-variables`: отдельная полная операция разрешения переменных одного элемента и расширенный контракт подстановки подготовленных значений для синтаксиса/`null` шаблона. Существующие правила A05 применяются без изменения семантики; новые требования уточняют границы операций и проверяемые результаты B02.

## Impact

Планируемые изменения — `internal/configuration`: новая операция `AssembleElement`, разбор строк шаблона, использование существующих `validVariableName`, `nullPath`, `Issue` и JSON-парсера; контрактные тесты и документация реализованного состояния. Новых зависимостей и I/O нет. Проверка идентичности остаётся отдельной ответственностью A08.

Существующая сигнатура `SubstituteValues` сохраняется. Её поведение вне прежней области корректных подготовленных шаблонов становится определённым: `null` и ошибочные ссылки отклоняются, `$$` преобразуется. `PrepareValues` сохраняет свой контракт; низкоуровневая подстановка по-прежнему не проверяет определения и обязательность.

Результат B02 — JSON одного элемента с разрешёнными переменными. Он не подтверждает валидность конфигурации Xray, зависимостей между элементами или готовность к публикации. Наследование, проекция `_xkeenUiId`, каталог файлов B12, БД, HTTP/UI, агент и устройства вне объёма. Макеты не затрагиваются.
