# Приёмка G17

Независимый разработчик сверил руководство и запустил указанную проверку с Go 1.27.1 в чистых контейнерах ARM64 Entware. Прошли проверка закреплённого bootstrap, установка и обновление агента, HTTPS и вход установленного администратора до и после рестарта, сохранение SQLite и отказ при недолговечном переключении.

Проверка использовала конкретные синтетические версии с теми же хешами, именами и HTTPS-путями, что указаны в контракте G12. Реальный GitHub Release и физические роутеры в проверке не участвовали.
