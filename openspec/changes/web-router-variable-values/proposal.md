## Why

Открыть разрешённую форму 10 для одного действующего роутера и UUID общего блока. Сохранять только персональные значения режима наследования. Новые поля из C04, разные UUID и удалённые определения не подменяют сохранённые значения. Условная запись черновика не меняет активную конфигурацию. [F12 #147](https://github.com/SunnyDayDev/xkeen-ui-server/issues/147).

## What Changes

Выделить один сценарий в существующей браузерной области, сохранив границы хранения и публикации.
