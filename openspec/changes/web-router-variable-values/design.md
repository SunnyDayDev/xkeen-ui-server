## Context

Открыть разрешённую форму 10 для одного действующего роутера и UUID общего блока. Сохранять только персональные значения режима наследования. Новые поля из C04, разные UUID и удалённые определения не подменяют сохранённые значения. Условная запись черновика не меняет активную конфигурацию. Используются F11, C04, B01, B04 и B05.

## Decisions

Читать C06 действующее назначение, точный принятый снимок и сохранённый C04 черновик в общем авторизованном SQLite snapshot. Если C04 черновика ещё нет, первый явный save берёт копию активных настроек с ожидаемым активным поколением и ожидаемым отсутствием черновика. Иначе сверяется поколение черновика и использованный шаблон; чужой ожидающий G01 переход не подменяется. В форме — один существующий общий UUID и C04 режим переменных. Дефолт наследуется при незаполненности по B01. Сохраняются точные значения и отдельность других настроек. Для исходных определений переиспользуются B01 и инспекция F08. Некорректный JSON не записывается. Структурно сохранённые значения могут оставаться неготовыми к сборке. Допуск редактирования проверяет объявленные имена выбранного UUID, а уже сохранённые другие данные не выбрасывает. Правка не меняет режим существующей полной замены. Мутация использует F03 guard и C04 compare-and-swap в одной writer-транзакции. Pencil 10 и связанный переход из фактически доступного роутера F11.

После F11 действие «Переменные» будет доступно из боковой панели выбранного видимого роутера в обзоре. Форма сначала показывает секции и UUID общих элементов принятого шаблона, затем определения только выбранного элемента. Условное чтение и запись используют точные RouterID и UUID. При исчезновении роутера из видимой проекции форма удерживает введённый буфер, а сервер не возвращает детали или не принимает устаревшую запись. Скрытие и возврат принадлежат G04/G05. Writer проверяет текущую видимость. Если контакт уже вернул тот же RouterID, разрешение определяется остальными проверками версии и сессии.

CAS связывает действующее назначение (ID шаблона и поколение активных настроек), принятую версию шаблона и ожидаемое поколение C04, где 0 означает отсутствие черновика. Все проверки вместе с F03 выполняются в одной writer-транзакции. Сохранение не занимается сборкой, Xray и публикацией. При неподходящем режиме или ожидающем назначении другого шаблона форма показывает отдельный отказ; существующий черновик сохраняется целиком.

Операция редактирует значения по имени выбранного элемента. Явное наследование означает удаление персональной записи выбранного имени. Текст JSON передаётся строкой и сохраняется байт-в-байт в C04; отсутствие значения, JSON `null`, пустая строка и `false` различаются. Для незаполненных или несовместимых значений использовать безопасные коды B01. Реализация может сгруппировать явные изменения нескольких полей одного UUID одним CAS; запись чужих имён и корневые преобразования чисел недопустимы.

## Risks / Trade-offs

Сетевой отказ и неполное доказательство не подтверждают изменение. Места ошибок и безопасные диагностические результаты сверяются с актуальными входами на штатном сервере.
