## Decisions

GET возвращает точное состояние маршрута списка, при наличии первого контакта и подтверждённой публикации. POST требует один сильный If-Match и только объект {"action":"hide","confirm":true}. Scope F20, подтверждённая публикация, присутствие и версия видимости проверяются одним writer. Сохранять монотонную версию успешного скрытия отдельно от временного маркера, чтобы старый ETag не стал пригоден после одного cycle hide → accepted contact → visible. Использовать тот же SQLite helper G04, которым регистрируется скрытие. D06 сохраняет прежний переход к видимости, обновляя контакт и удаляя маркер в одном writer. Выбранное имя, ID, рабочий ключ, приглашения, назначения, курсор и журналы сохраняются. Скрытие оставляет возможность прямого доступа по точному ID при действующих полномочиях. Другие операции записи отсутствуют.

## Risks / Trade-offs

F20 действует по явной настройке владельца. Точные значения и цели проверяются на момент чтения или транзакции записи.
