## Context

Раздел 3 прототипа определяет изменение имени на странице роутера. #190 добавляет отдельное версионированное имя, чтение видимого подтверждённого роутера и проекцию имени в обзоре. Web и внешний API используют разные допуски, общий переход имени и одинаковую валидацию.

## Decisions

- Карточка F11 предлагает кнопку редактирования и явные сохранение и отмену. Авторизованное чтение предоставляет точный ID, имя, версию и поколение активного назначения. Представление поколений использует десятичные строки.
- Сервер повторно проверяет F03/CSRF, видимость и основание в том же SQLite writer, который меняет имя. Сохранение и отображение используют те же правила, что #190. Профиль и другие данные не перезаписываются.
- При stale сохраняется введённый текст. Явное чтение показывает текущий снимок, после которого владелец самостоятельно решает, сохранить ли ввод. При неизвестном результате повторное чтение не приписывает найденное имя конкретному вызову.
- Карточка, несохранённый текст и фокус привязаны к точному RouterID. Переход на другого роутера либо поздний ответ не переносит форму. Операция проверяется на ширине 320 px и с клавиатуры.
