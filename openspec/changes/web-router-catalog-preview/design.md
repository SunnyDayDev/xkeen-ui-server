## Context

Показывать и скачивать только фактически собранные файлы явного кандидата роутера, сохраняя неизвестные поля и точность. Отдельно указать обязательные ошибки сборки, не выдавать частичный результат и не публиковать. Используются F16, B12, C06.

## Decisions

Различить активные принятые файлы и явную сборку предпросмотра C04 с точным принятым общим снимком. Прикладной сценарий использует C06.1 PrepareRouterCandidate и полученный B12 каталог, а не парсит и собирает Xray заново. Получение выполняется из авторизованного входного снимка; дополнительные выдачи после длительной подготовки повторно сверяют активность сессии. Один ответ с установленным no-store передаёт точные именованные байты для просмотра и скачивания. Имя загрузки берётся из безопасного имени B12, журналы не содержат исходные JSON и реквизиты. Ошибка B06/B08/B10/B11/B12 возвращает безопасную диагностику без частичного каталога. Не подтверждать серверный -test или применение, если был только B12. Pencil 07, ошибки, точный просмотр и загрузка.

## Risks / Trade-offs

Сетевой отказ и неполное доказательство не подтверждают изменение. Места ошибок и безопасные диагностические результаты сверяются с актуальными входами на штатном сервере.

## Снимок и передача файлов

Действующие файлы означают текущую сохранённую желаемую ревизию C06. Их просмотр не утверждает применение. «Собрать предпросмотр» явно выбирает сохранённые персональные настройки C04 и точный принятый снимок для активного назначения. Если персональный черновик отсутствует, используется действующий персональный снимок. Для сохранённого персонального порядка применяется его собственное основание F14. Прежняя запись без такого основания использует действующее основание только при доказанном совпадении полного порядка и локального состава; иначе предпросмотр отклоняется с диагностикой. Если черновик относится к предварительной смене назначения, он недоступен в этом режиме до подтверждения смены. Снимок проверяет точный RouterID, допуск F03 и видимость G05 в одном чтении. Перед ответом после сборки отдельное чтение перепроверяет действующую сессию и версии использованных входов. При их изменении пользователь получает предложение перечитать источник.

Приватное действие получает один полный снимок файлов с точными UTF-8 байтами и безопасными именами каталога. Браузер показывает исходный текст без форматирования и создаёт действительную загрузку Blob из сохранённых байтов того же ответа. Файл не собирается и не форматируется повторно. При смене источника, роутера или сессии результаты и адреса Blob очищаются. Повторный вход не повторяет сборку.
