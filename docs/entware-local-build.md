# Локальная сборка комплекта Entware

Для сборки при необходимости используйте Git checkout проекта, версию Go из директивы toolchain в go.mod, POSIX shell, tar, file и sha256sum либо shasum. Сборщик читает отслеживаемые файлы текущего коммита HEAD, включая встроенную веб-оболочку и install-entware.sh. Предварительно загрузите Go-модули для автономной сборки.

Пример синтетической версии для местной проверки:

```sh
sh scripts/build-entware-release.sh v0.0.0 .build/entware-bundles
```

Выберите каталог под контролем владельца. Параллельные вызовы этого сборщика блокируются по версии; посторонним программам не следует создавать целевой каталог во время сборки.

Готовый каталог `.build/entware-bundles/v0.0.0/` содержит:

- Четыре статических Linux ARM64 исполняемых файла: xkeen-agent-linux-arm64, xkeen-local-validator-linux-arm64, xkeen-entware-installer-linux-arm64 и xkeen-ui-server-linux-arm64.
- agent-state-format.txt и SHA256SUMS для проверки четырёх программ и формата транспортного состояния.
- Точную копию install-entware.sh и owner-verification.txt с версией, коммитом исходников, SHA-256 скрипта и самого манифеста.

В каталоге комплекта выполните `sha256sum -c SHA256SUMS` или `shasum -a 256 -c SHA256SUMS`. Сборщик перед выдачей проверяет статическую компоновку и метаданные Go и отказывает при существующем выходном каталоге этой версии. Для повторной проверки той же версии выберите другой выходной каталог и сравните результаты.

Команда работает локально и не требует учётной записи GitHub. Установщику, использующему HTTPS, требуются файлы выбранной версии в доверенном источнике и независимо полученный хеш манифеста. Методика G17/G18 проверяет их через синтетическое локальное зеркало. [Чистая установка](entware-clean-install.md).
